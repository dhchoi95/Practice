# 1.4.0 조립 결과 재독 메모

2026-10-22. 구현자가 한 번에 읽은 기록이며 독립 전문가 승인이나 자동 문체 점수가 아니다. 전문은 reports/content-improvement-1.4.0/assembled-preview.md와 JSON에 있다. 기존 6개 계산 feature·계산 버전은 기준 자료와 대조하고, 병화 종합·월간·일간·일간 미확정 성격 4개를 더 읽었다.

| 결과 | 반복과 문맥 | 행동 순서·뜻의 한계 |
|---|---|---|

| assembled-order-love | 기본의 바람 전달과 관성의 약속을 못 지키는 날 알릴 방법을 나누었다. 화 보완의 공개 동의는 개인적인 대화와 다르다. | 혼인이나 배우자 존재를 예고하지 않고 실제 동의·행동을 우선한다. |
| assembled-career | 기본은 맡을 범위와 추가 보수, 식상은 실제 사용자의 의견, 목은 도구 학습의 시간·돈이다. | 필수 오류를 먼저 고친 뒤 작은 초안을 보여주는 순서를 유지했다. 추가 부탁과 오류 수정을 같은 것으로 처리하지 않는다. |
| assembled-general | 집안 정리·실수 뒤 자기평가·수정 부탁·개인적인 바람·말투 차이로 역할을 나누었다. 말·글·사진 보완은 일을 더 맡으라는 뜻이 아니다. | 안전·생활의 필수 수정과 취향 정리를 나눴다. 1,800자 제한·실제 표시 문단/제안 trace를 유지했다. |
| assembled-annual | 새 활동의 시간·비용과 이미 맡은 일의 변경을 다른 내용으로 읽는다. | 앞 구간이 약 한 달이어도 분기·연간 전체 과제를 넣지 않는다. 화면의 실제 날짜와 정확한 경계 시각을 함께 본다. |
| assembled-unknown | 미확정 계산 안내 뒤 일반적인 목 이야기와 시간 미상 연애 안내만 남는다. | 일간을 채우거나 확정한 연애 성격이라고 부르지 않는다. 현재 상대가 없는 경우도 읽을 수 있다. |
| assembled-fire-general | 모임 뒤 휴식·말하며 생각 정리·완료한 작업의 발표·연락 빈도·다른 사람의 말할 차례가 구별된다. | 밝은 모습이나 말솜씨를 의무로 만들지 않는다. 좋은 일이 생긴 주체와 연락을 받는 상대가 뒤바뀌지 않도록 다시 고쳤다. |
| assembled-month | 편관 구간의 도움 요청과 정인 구간의 배운 설명 활용을 구별한다. | 절기 안에 모든 일을 끝내거나 새 교육비를 쓰라고 요구하지 않는다. 실제 구간의 날짜·관계만 적용한다. |

한계 안내는 뜻을 바꾸지 않기 위해 유지했다. 문자열이 다른 것만으로 의미 중복이 없다고 판정하지 않았다. 직접 읽은 대표 결과 밖의 모든 가능한 조합을 사람이 검수했다는 주장도 하지 않는다.
