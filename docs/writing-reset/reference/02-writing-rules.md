# 운세 본문 집필 기준 — VIDEO-KO-1
이 문서는 이번 작업의 운세 문체 기준이다. 이전 대화에서 만든 문체·분량·문단 규칙과 충돌하면 본 문서를 우선한다. 계산과 개인정보, 카테고리 분리는 유지한다. 홈페이지 디자인을 바꾸는 지시가 아니다.

## 1. 지금까지 글이 어색했던 이유
실제 기존 원고에는 “원국의 약한 쪽 후보”, “기간 천간과 지지 본기”, “주제로 읽었어요”, “범위를 구분해 보세요” 같은 말이 반복됐다. 전문 근거를 빠짐없이 본문에 설명하려다 독자가 어떤 운세인지 알기 어려워졌다. 이후 쉬운 단어로 바꾼 글도 요청·담당·완료 기준·점검 같은 업무 관리 조언으로 기울었다.

이번에는 ‘쉽게 쓴 운세’가 목표다. 첫 문장에서 어떤 시기인지 알 수 있어야 하며, 뒤의 상황과 조언이 그 판단을 자연스럽게 이어야 한다.

## 2. 이전 지시에서 철회하거나 완화할 것

| 이전 규칙·경향 | 이번 기준 |
|---|---|
| 기본 해요체 고정 | 운세 본문은 자연스러운 합니다체로 통일. 버튼·짧은 안내는 별도 |
| 모든 문단에서 원국·기간·근거 설명 | 근거는 데이터·별도 해설에 보존. 일반 운세 본문은 독자의 상황부터 설명 |
| 실제 사건을 말하면 안 된다는 이유로 조언만 작성 | 기회·부담·관계·일의 진행을 운세의 가능성으로 먼저 말하고 조언으로 연결 |
| 후보·유보·확정하지 않음 등의 문구 반복 | 불확실한 계산값은 분명히 안내하되, 일반 본문에 같은 주의문을 반복하지 않음 |
| 추상어를 모두 피하기 | ‘운·기회·기운·성과·인연’은 뜻이 드러나는 문장에서 사용 가능 |
| 항상 네 단계·고정 글자 수 | 자연스러운 흐름을 우선하고 내용이 충분할 때 마침 |
| 계획·확인·역할·비용을 여섯 분야 모두에 반복 | 각 분야의 실제 관심사에 맞는 상황과 어휘 사용 |
| 원고 수·고유 본문 수부터 늘리기 | 좋은 완성 문단을 확보한 뒤 필요한 조건을 채움 |
| 문장 조각을 여러 원고에서 모아 붙이기 | 한 문단은 하나의 판단을 끝까지 설명. 문단 사이도 함께 읽고 편집 |

철회하지 않는 것:
- 출생·시각·역법 계산, 선정 조건·제외 조건, 버전과 근거 추적.
- 같은 입력·같은 기간·같은 버전의 재현성.
- 메인 디자인 보존과 각 카테고리의 내용 분리.
- 현실의 의료·투자·합격·혼인·외도·상대 의도를 사실처럼 확정하지 않는 원칙.
- 개인정보 처리와 런타임 LLM/API 미사용.

이 작업은 대화 기록이나 과거 파일을 삭제하는 작업이 아니다. 현재 적용할 집필 규칙의 우선순위를 다시 정하는 작업이다. 과거 원고와 이력은 보존한다.

## 3. 영상에서 채택한 특성

### 첫 문장에서 판단한다
읽고 나서 ‘그래서 좋다는 건가, 조심하라는 건가’를 다시 묻게 하지 않는다.
- 좋은 시기: 준비한 것을 드러내거나 기회를 활용하기 좋다는 결론.
- 무난한 시기: 유지·꾸준함·작은 진전이라는 결론.
- 신중한 시기: 서두름·과욕·오해 등 무엇을 조심할지 밝힌다.

모든 원고를 “오늘은 ~한 날입니다”로 시작할 필요는 없다. “작은 성과를 이어가기 좋은 때입니다”, “마음이 앞서면 중요한 조건을 놓치기 쉽겠습니다”처럼 변형한다.

### 한 문단에 하나의 흐름
핵심 판단 → 일상에서 나타날 법한 상황 → 반대 요인이나 주의점 → 짧은 마무리.
이 순서를 독자가 따라갈 수 있으면 된다. 항상 네 문장으로 맞추지 않는다.

예: 일을 내놓기 좋음 → 준비한 내용·작은 결과를 보여줌 → 새 일을 과하게 늘리지는 않음 → 한 가지 결과를 마치는 쪽으로 권함.

### 합니다체를 자연스럽게 섞는다
기본 어미:
- ~입니다 / ~겠습니다.
- ~할 수 있습니다.
- ~하는 편이 좋습니다 / 좋겠습니다.
- ~하기 바랍니다 / ~하시기 바랍니다.
- ~할 필요가 있습니다.

문장마다 “가능성이 있을 수 있겠습니다”처럼 가능 표현을 겹치지 않는다. “~할 수 있습니다”면 충분한 경우가 많다. 모든 문장을 명령으로 끝내지 않는다.

### 일상적인 상황을 쓴다
돈은 들어올 돈·나갈 돈·정산·계약·가격으로, 일은 맡은 일·평가·제안·협력으로 쓴다. “자원과 과제를 연결하는 관계”로 돌려 말하지 않는다.

연애는 연락·약속·마음 표현·거리감·대화로, 공부는 이해·복습·답안·진도로 쓴다. 건강은 쉬는 시간·생활 리듬·무리한 일정 등 생활 범위를 지킨다.

### 한 번에 읽히는 접속
‘다만·하지만·반면·또한·한편·그러므로’를 필요한 곳에 쓴다. 근거 없이 긍정과 부정을 번갈아 붙이지 않는다. 서로 다른 문단의 내용을 잇기 위해 “흐름·구조·주제”만 반복하지 않는다.

## 4. 그대로 따르지 않는 특성
- ‘병이 생긴다’, ‘상대가 바람을 피운다’, ‘돈을 날린다’, ‘승진한다’를 실제 사실처럼 확정하는 표현.
- 특정 나이·성별·현재 직장·연애 상태를 출생 정보만으로 전제하는 문장.
- 지시를 따르지 않으면 반드시 불행해진다는 공포 유발.
- “호구”, “능력이 부족하다” 등 독자를 깎아내리는 표현.
- ‘긍정적인 에너지·소중한 시간·더욱 강조·도움을 줍니다’를 내용 없이 반복하는 코디 문단.
- 영상 속 인상적인 비유와 문단을 그대로 돌려 쓰기.
- 별자리의 반말을 개인 사주 본문에 섞기.

영상의 문체를 참고한다는 것은 그 앱의 계산이나 사건 예언을 검증한 것으로 취급한다는 뜻이 아니다. 서비스는 독립 집필한 원고를 사용한다.

## 5. 분량은 읽는 단위에 맞춘다
- 일운의 일반 분야: 보통 3~5문장, 약 160~300자에서 출발.
- 일운 총운: 필요하면 5~8문장.
- 월운: 한 달의 유지·진행·조정이 드러나는 1~2문단.
- 연운: 장기 방향·기회·부담을 나누는 2~3문단.
- 띠별 짧은 글: 제목 한 줄 + 2~4문장. 개인 사주처럼 보이지 않게 구별.
- 정통사주: 전문 용어를 지울 필요는 없다. 용어 뒤에 뜻을 설명하고 그 결과의 의미를 읽기 쉽게 쓴다.

글자 수를 맞추려고 반복 문장을 추가하지 않는다. 자세한 근거가 필요한 사주는 상세 해설에서 제공한다.

## 6. 기술적 해석과 독자용 문장을 분리한다

내부 자료 예:
- 분야: 사업.
- 대상: 하루.
- 판단: 준비한 내용을 결과로 보여주기.
- 조건: 실제 레코드의 requires 그대로.
- 반대 요인: 과도한 새 업무 확장 경계.
- 제외할 단정: 승진·채용·매출 확정.

독자용 문장 예:
“준비한 일을 밖으로 내놓기 좋은 날입니다. 설명만 이어가기보다 작은 결과를 보여주면 자신의 생각을 전하기 쉬워집니다. 다만 의욕이 앞서 새 약속까지 한꺼번에 늘리지는 않는 편이 좋겠습니다. 지금 끝낼 수 있는 일에 힘을 모으시기 바랍니다.”

내부 조건의 전문 용어를 이 문단에 모두 적을 필요는 없다. 그렇다고 조건과 다른 성공 이야기를 만들어도 되는 것은 아니다.

## 7. 분야별 편집 초점
- 총운: 우선할 일, 하루·기간의 전반적인 방향. 다른 분야 내용을 길게 복사하지 않음.
- 학업: 이해·기억·표현·답안·진도. 학생이라고 단정하지 않음.
- 재물: 지출·관리·분배·기회·조건. 수익률·당첨·원금 보장 없음.
- 건강: 생활의 여유·휴식·일정. 질병·장기·수명·치료 추정 없음.
- 연애: 표현·만남·대화·약속. 현재 연애 상태와 상대의 의도 추정 없음.
- 사업: 일·취업 준비·평가·제안·협업·진행. 재물운과 같은 문장을 재사용하지 않음.

## 8. 추가 샘플을 만드는 방법
원문을 많이 늘리는 것보다 실제 서비스 조건의 범위를 넓힌다.
1. 유지할 해석과 적용 조건을 한 줄 브리프로 정한다.
2. 같은 분야·같은 기간의 좋은 참고 형식을 고른다.
3. 새 상황과 독립된 어휘로 완성 문단을 쓴다.
4. 긍정·신중·중립, 짧은 문단·긴 문단을 고르게 확보한다.
5. 추가 생성문에는 synthetic 또는 editorial-draft 상태를 붙인다.

생성문을 7개 영상의 관찰 사실, 독립 명리 근거, 외부 검수 결과로 다시 세지 않는다. 한 모델이 만든 글을 같은 모델이 좋아한다고 해서 검수 완료로 보지 않는다.

## 9. 최종 읽기 질문
자동 수치 대신 완성된 여섯 분야를 실제로 읽는다.
- 첫 문장만 읽고 무슨 운세인지 알 수 있는가?
- 누가 무엇을 어떻게 한다는 문장인지 분명한가?
- 전문 용어를 몰라도 뜻이 통하는가?
- 같은 조언을 앞뒤에서 다시 하고 있지 않은가?
- 업무 지시문이나 상담용 질문지가 아니라 운세 본문으로 읽히는가?
- 원래의 해석과 주의할 부분을 유지했는가?
- 앞 문장과 다음 문장이 자연스럽게 연결되는가?
- 다른 분야의 제목을 붙여도 똑같이 읽히는 공통 조언뿐이지 않은가?

기계적인 조사 교체·어미 랜덤화·AI 탐지 점수는 자연스러움의 증거가 아니다. 스키마·참조·기간·전제 검사는 별도로 수행한다.
