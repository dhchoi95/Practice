# 화면과 카테고리 유지 기준

- 메인은 2.0.0의 카드·배너·여백·상단 바로가기 구조를 유지한다. 큰 분류 박스나 새 랜딩 화면을 추가하지 않는다.
- 새 기능은 전체 메뉴에 독립 항목으로 추가한다. 기능 추가를 메인 재디자인의 허가로 해석하지 않는다.
- 오늘은 오늘, 내일은 내일, 이번 달은 이번 달, 올해는 올해만 보여준다.
- 날짜 입력과 면접·시험 등의 일정 선택은 지정일 운세에만 둔다. 지정일을 고르기 전에는 오늘 운세를 대신 보여주지 않는다.
- 다른 메뉴로 이동하는 기능은 공통 메뉴에 둔다. 풀이 본문 안에 다른 날짜의 결과·폼·추천 패널을 섞지 않는다.
- 성격·연애 등 주제 메뉴에서 상세 계산 옵션을 선택해도 정통사주 전체 보고서를 대신 보여주지 않는다.
- 정통사주는 원국·분야 해석·대운·세운, 만세력은 사주표·관계·계산 해설을 중심으로 한다.
- 사용자 본문은 일상적인 한국어로 쓴다. 전문 용어가 필요한 근거와 개발자용 기록은 본문과 구분한다.
- 이 수정에서 점수 계산과 출생·역법 계산은 변경하지 않는다. 점수 표시 방식은 별도 결정 사항이다.
