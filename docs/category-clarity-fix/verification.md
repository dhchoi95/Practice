# 2.2.1 카테고리 분리와 문구 수정

사용자의 직접 요청은 기존 메인 화면 복원, 기능만 추가, 각 메뉴에 해당 내용만 표시, 쉬운 문구다. 첨부 ZIP의 README는 제안 패치의 설명·작업 지침으로 읽고 실제 변경과 대조했다. 첨부 문서의 통과 수치를 이번 실행 결과로 사용하지 않았다. 기준은 사주 브랜치의1c9f24e이며 식당 앱 브랜치는 변경하지 않는다.

## 패치 검토와 추가 수정

- changes.patch는 충돌 없이 적용됐고23개 변경 파일의 SHA-256이 첨부 manifest와 같았다. 이후 실제 화면·문맥 검토에서 필요한 추가 수정을 했다. 이 때문에 최종 파일은 첨부 after 해시와 다를 수 있다.
- 메인은2.0.0 카드9개·배너·오늘 패널·8개 상단 바로가기 구성을 복원했다. 추가했던 큰 분류 박스를 없앴다. 새 메뉴는 공통 전체 메뉴에서 찾는다. 새 레이아웃을 만들지 않았다.
- 오늘·내일·이달·올해 결과에는 각각 그 기간의 사주표·그래프·여섯 분야 본문만 표시한다. 다른 날짜 버튼·날짜 입력·일정 선택·다른 카테고리 결과 패널은 제거했다. 카테고리 이동은 공통 메뉴로 한다.
- 지정일 운세만 날짜 입력과 일정 선택을 갖는다. 처음 진입하거나 날짜를 지우면 사주표는 유지하고 결과를 보류한다. 임의로 오늘 운세를 대신 표시하지 않는다. 일정 선택은 같은 날짜의 기본 점수·본문을 바꾸지 않는다.
- 성격·연애사주·직업재물·대인관계 등 주제 메뉴는 상세 옵션을 선택해도 정통사주 전체 보고서가 되지 않는다. 정통사주의 임의 날짜 조회를 없애고 대운·5년 세운은 유지했다.
- 추가 검토에서 주제 메뉴의 표는 태양시인데 풀이 조건은 표준시가 될 수 있음을 확인했다. 같은 선택 원국에서 기존 단순 개수·천간 관계 특징을 읽는 topicBasis를 추가해 표·풀이를 맞췄다. 표준시 입력에서는 기존 특징과 정확히 같고, 태양시에서 일주가 달라지는 사례와 일간 미확정 사례를 검사했다. 역법·태양시·대운 계산 함수는 수정하지 않았다.
- 일반 방문 화면의 개발자 JSON 패널을 제거했다. 개발 검사 함수·원고ID·검토 이력과 사용자용 시기별 근거는 유지했다.

## 문구

첨부 패치의 쉬운 첫 문단을 적용했다. 추가로 뒷문단248개 레코드에 남은 전문 용어·어색한 구문을 문장 단위로 고쳤다. 겹친 레코드가 있어 첨부360개와248개를 합해 수정 원고 수로 세지 않는다. 전체540개 중 실제 문구 또는 버전이 변경된 레코드는469개다. 원문과 전후는 copy-edits.json과 followup-copy-edits.json, 기존 검토 스냅샷에 보존했다. 독립 편집·명리 승인은 계속 대기다.

실제 예:

- “기간의 비겁 주제를 자기 판단과 함께하는 사람의 역할을 나누는 방향으로 읽었어요.” → “내 판단을 지키면서도 다른 사람과 맡을 일을 나누는 것이 중요해요.” 독자가 할 수 있는 일을 바로 설명했다.
- “세운의 관성을 평가자가 실제로 정한 기준으로 혼동하지 않아요.” → “운세보다 시험이나 과제의 실제 평가 기준을 먼저 확인해 주세요.” 전문 용어 없이 해석과 실제 기준의 차이를 남겼다.
- “대운·세운의 재성 주제로 매출이나 취업을 예측하지 않아요.” → “매출이나 취업 여부를 예측한 설명은 아니에요.” 제한은 유지하면서 뜻을 곧바로 알 수 있게 썼다.

기존 한국어 문체 기준과 humanizer·grammar-checker·style-guide 참조를 따랐다. AI 탐지 등급·수정률·오타·어미 무작위화는 합격 기준으로 사용하지 않았다. 전문 계산 용어는 만세력·상세 근거에서 필요한 경우 유지한다.

## 직접 검증

- npm run verify: 단위·통합388개 및 모든 콘텐츠·호환성·검토 이력 검사 통과. lint·typecheck는 새 검사 스크립트와 E2E 추가 후 별도 재실행해 통과했다.
- npm run build 및245개 정적 파일의 초안 유출 검사 통과. 새 npm ci를 실행했다고 보고하지 않는다.
- Chromium E2E83개 통과. 기존80개와 추가3개를 한 번에 실행했다. 320/390px의 복원된 메인·고정 기간4개·지정일·보정 원국의 주제 메뉴를 확인했다. 초기 별도 E2E 두 실행이 결과 폴더를 공유해 아티팩트 충돌이 있었으므로, 최종 실행은 독립된 출력 폴더를 사용했다.
- 실제 Chromium PDF24개 검사 통과. 사주표 좌표·6개 본문·벡터 그래프·계산 기준·연도 경계·접힘 복원·본문 중복·미확정 안내를 확인했다. 제목·안내를 바꾼 항목의 예상 문구는 새 제품 동작에 맞췄으며 해당 검사 자체를 삭제하거나 건너뛰지 않았다.
- 원고540개의 전제·제외·우선순위·점수 기여 변경0건. 고정12명의365일·12개월·5년 실제 구간·분야33,564건에서 선택 ID 변경0건. 점수 산식·정책도 유지했다.

별도 실제 휴대전화·인스타그램 인앱 브라우저와 명리 원전의 독립 검토는 이번 검사에 포함하지 않는다. 이 수정은 기존2.2.0의10일 반복 문제를 해결했다고 주장하지 않는다.

운영 반영 결과는 배포한 Worker 버전과 공개 URL에서 별도로 확인한다. 소스 수정·로컬 검사 통과만으로 운영 반영됐다고 판단하지 않는다.
