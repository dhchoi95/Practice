## 2. 남은 지적 — F-01-R

**P2 / 수정 필요 / 확신도 높음.** 기존 F-01의 잔여 문제이며, 잘못된 일간을 산출하는 계산 오류로 판정한 것은 아니다.

**근거 파일**

- `src/components/FortuneResult.tsx:57`: 일간 확정 여부와 관계없이 “내 일간과의 관계를 살폈어요”를 출력한다. 연간·월간에는 “구간별 내용을 요약해서 함께 보여드려요”도 출력한다.

- `tests/e2e/site.spec.ts:106–117`: 본문 `.result-content`의 중립 안내를 검사하지만, 기간 상세를 펼쳐 문장이 일치하는지는 검사하지 않는다. 테스트 50개가 통과해도 이 문제가 남는 이유다.

**재현 방법**

1. 성격풀이 입력 화면에서 양력 `1987-06-01`, `시간 모름`으로 조회한다. 별명은 없어도 된다.
2. 같은 정보로 `올해 운세`, `이번 달 운세`, `오늘 운세`를 각각 연다.
3. `대상 기간과 절기 구간 보기`를 펼친다.
4. 같은 결과를 인쇄 PDF로 저장한다. 상세를 미리 펼치지 않아도 인쇄 훅이 펼친다.

**예상 동작**

일간 미확정이므로 “기간의 간지와 경계만 표시하며, 나의 일간과의 관계 해석은 제공하지 않는다”는 취지로 설명해야 한다. 실제로 제공하지 않은 구간 해석을 요약했다고 말하지 않아야 한다. 기간 간지와 날짜 경계 자체는 계속 표시할 수 있다.

**실제 동작**

- 세 메뉴 모두 본문에는 “일주와 일간을 확정하지 않았어요”, “기간 해석은 적용하지 않아요”가 정상 표시된다.
- 같은 화면의 상세에는 “내 일간과의 관계를 살폈어요”가 나온다. 바로 아래 실제 값은 `일간과의 관계 미확정`이다.
- 연간·월간에는 실제 본문이 중립 안내인데도 “구간별 내용을 요약해서 함께 보여드려요”가 붙는다.
- 새로 만든 실제 연간 PDF에서도 같은 모순 문장이 추출됐다. 화면에만 한정된 문제가 아니다.

**수정 방향**

`birth.calculation.dayMaster`의 확정 여부에 따라 기간 상세의 도입 문장을 나눈다. 미확정이면 관계 해석 및 구간 풀이 요약을 했다는 문장을 제외한다. 예: “일간이 미확정이라 나의 일간과 기간 간지의 관계는 해석하지 않았어요. 아래에는 대상 기간의 간지와 경계만 표시해요.” 확정된 경우의 기존 안내는 유지한다.

회귀 검사는 위 입력으로 연간·월간·일간의 **펼친 상세와 실제 인쇄 PDF**를 포함해야 한다. “관계를 살폈다”는 주장 부재와 관계값 미확정을 함께 검사하고, 일간이 확정된 일반 입력에서도 기존 상세 설명이 유지되는지 확인한다. 달력 계산이나 일간 산출 정책을 변경할 사안은 아니다.

## 6. 개인정보·화면·흐름의 회귀

`SessionProvider.tsx:8–12`는 메모리 상태를 사용한다. 출생정보를 DB에 저장하는 경로나 실행 중 AI API 호출을 발견하지 않았다. `sharing.ts`, `ShareActions.tsx`는 개인 결과가 아닌 일반 메뉴 링크를 공유한다. 개인정보 안내도 현재 구조와 대체로 일치하며, 일반 호스팅 접속 로그 가능성을 별도로 설명한다.

기존 E2E의 개인정보 검사와 별도 독립 재현을 모두 실행했다. 독립 시나리오에서 관찰한 요청 69개는 GET뿐이었고 요청 본문은 없었다. 입력한 고유 별명, 출생 날짜·시각의 직렬화 값이 요청·URL·콘솔에 포함되지 않았으며, localStorage·sessionStorage·문서 쿠키·브라우저 쿠키는 비어 있었다. 새로고침 뒤 입력 없음 안내가 나왔다. 이는 **실행한 시나리오에서의 관찰 결과**이며, 아직 없는 공개 호스팅 사업자의 로그까지 확인한 결과는 아니다.

검사한 흐름에는 오류 입력과 포커스, 윤달·존재하지 않는 날짜, 시·분 누락, DST 중복·누락 시각, 같은 정보 재사용, 다른 사람 보기, 입력 삭제, 결과 직접 진입·새로고침, 공유 성공·취소·복사·수동 복사, 악성 별명 텍스트 처리, 키보드 메뉴, JavaScript 비활성 시 전송 방지, 404, 정적 경로, 결과 noindex가 포함된다. axe 검사는 지정된 홈·메뉴·폼·펼친 결과에서 통과했다.

화면은 원래 참고 이미지의 다중 운세 메뉴·바둑판 배열·짙은 분류 띠를 유지하면서, 차분한 아이보리·먹색·붉은 강조와 자체 SVG 그림으로 정돈했다. 과도한 그라데이션·유리 효과·챗봇 중심 화면은 아니다. 2030 유입과 중장년 독자를 함께 고려한 방향에 부합한다고 판단한다. 다만 연령대별 실제 사용성 조사를 한 것은 아니다. 본문은 읽기 중심이고, 확대한 별자리 날짜가 더 이상 10px에 머물지 않는다.

첨부 PDF 34쪽은 캡처 전체의 연속 영역을 확인하는 용도로 읽었다. 새로 만든 화면에서도 입력·결과·별자리와 잔여 문제를 확인했다. 화면 캡처를 계산 정확성 증거로 대신 쓰지 않았다.
