# 점수·원고 개선 검증 보고

기준선은 커밋 7297ae6, 개선 후는 점수 정책 3.0.0·콘텐츠 2.4.4다. 생성 인물은 실제 사람이 아닌 재현 가능한 합성 출생정보이며 1,000명 각각에 7개의 같은 기준일을 적용했다. 각 7,000회, 여섯 분야 42,000개를 실행했다. 56회는 일간 미확정으로 336개 점수를 보류했으며 각 분야 유효 값은 6,944개다.

| 분야 | 45~55점 이전 → 이후 | 이후 범위 / 중앙값 | 동일 본문 재등장 비율 |
|---|---:|---:|---:|
| 총운 | 96.3% → 80.5% | 40~70 / 50 | 97.1% |
| 학업 | 96.0% → 44.3% | 40~80 / 50 | 97.5% |
| 재물 | 89.7% → 35.2% | 30~80 / 50 | 97.7% |
| 건강 | 95.8% → 43.9% | 30~70 / 50 | 97.0% |
| 연애 | 96.6% → 60.9% | 30~70 / 50 | 97.5% |
| 사업 | 87.4% → 44.1% | 40~80 / 60 | 96.8% |

동일 본문 재등장은 일곱 날짜와 여러 사람에 걸친 정확한 텍스트 재사용을 7,000회로 나눈 수치이며, 정상적인 재사용 및 미확정 빈 결과도 포함한다. 의미 중복·문장 품질의 확정 판정이 아니다. 일일 원고 180개 중 158개가 선택돼 22개는 해당 표본에 나타나지 않았다. 규칙 충돌 자동 검사는 선택된 원고 쌍의 명시적 상충군·중복군·의미축·양립 금지·동일 문단을 확인하며, 실제 문맥의 뜻이 모순되지 않는다는 독립 검토는 아니다.

가상 120명의 일일 여섯 분야 총 720개 결과는 별도 파일럿 10명 및 synthetic-0011~0120의 편집 검토 기록에서 읽었다. 10인 파일럿은 분야별 대체 문장 초안 60개, 나머지 110명은 최소 사례별 대체 문장 초안을 작성했다. 초안은 미검증이며 자동 운영 적용하지 않는다. 실제 운영에 적용한 조건부 원고는 17개를 직접 교정했고, 전제·점수 기여는 보존했다. 모든 원고를 새로 쓰거나 모든 본문이 두 문단이라고 주장하지 않는다.

분포 확대는 기존 명리 관계 기반 원점수에 단조 표시 변환을 적용한 것이다. 원점수의 새로운 가중치 검증은 완료되지 않았다. 분야별 원고와 기여 규칙이 항상 의미상 일치하는지, 사용자 간 반복이 충분히 줄었는지, 독립 명리 전문가 검토와 실기기 인앱 검증은 남았다. 생산 환경에 런타임 LLM을 추가하지 않았다.
