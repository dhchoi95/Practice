# 추가 사례 20명: 일일 원고 수기 검토

2026-11-08 작업 중 서비스의 `calculateAdvanced` → `buildSectorReading` → `presentSector`를 실행한 결과를 읽었다. 입력은 `reports/synthetic-validation-baseline/inputs.json`의 synthetic-0011~0030, 기준일은 모두 2026-01-15, standard 시간 정책이다. 계산기의 일진 인덱스는 천간 5·지지 1이다. 최초 10인 파일럿과 겹치지 않는다. 아래는 이 시점의 선택 결과에 대한 편집 검토이지, 자동 생성 전체를 사람 검증으로 표시한 것이 아니다. 20명 × 6분야 = 120개 분야의 제목·표시 점수·선택 문단을 읽었다. 원고가 동일한 경우에도 같은 결과의 다른 원국을 대조했다. 실제 브라우저나 모바일 화면, 토글, 레이더·그래프, 원점수의 상세 추적 및 독립적인 역법·명리학 검증은 하지 않았다. 본문이 화면에서 어떻게 줄바꿈되는지도 확인하지 않았다. 일일 원고 한 날짜만 봤으므로 월간·연간과 다른 날짜에 관한 결론은 낼 수 없다.

## 분야별 평가 및 재사용 가능한 개선안

- **총운**: 0013 peer와 detail-07(0029)은 자기 판단과 다른 의견을 듣는 주제가 가깝다. 핵심에는 일진 천간과 일간의 관계를 짧게 밝혀 주고, 보조는 같은 주제 재진술일 경우 제외한다. 예: 「오늘 천간은 일간과 비견·겁재로 묶이는 관계예요. 내 방식과 다른 의견을 함께 살펴보는 상징으로 읽어요.」 실제 fact가 비견 또는 겁재일 때만 사용한다.
- **학업**: 0012 output의 책 덮고 기억하기는 행동이 분명하다. 다만 mixed-year-month도 이유 설명을 확인해 같은 학습 점검을 반복한다. 핵심이 이미 이해 확인이라면 보조를 생략하거나 실제로 다른 근거가 계산된 경우에만 다른 행동으로 바꾼다.
- **재물**: 0020의 `sector:day:money:detail-02`와 `supplement:day:money:supported-preparation`, 0017의 agreement와 detail-05는 의미가 중복된다. 같은 화면에서 각각 한 개만 선택하도록 의미 충돌을 지정한다. 납부·비용은 실제로 존재하는 사건처럼 단정하지 않고 「납부할 금액이 있다면」처럼 조건을 붙인다.
- **건강**: 0024의 `sector:day:health:peer`와 `sector:day:health:detail-07`은 둘 다 남의 활동량을 따라가지 않고 쉰다는 뜻이다. 하나만 선택하고 0011처럼 식사 문단이 연속될 때도 같은 처리를 한다. 의료 진단이나 증상 예측은 하지 않는다.
- **연애**: 0020의 `sector:day:love:day-clash`와 `supplement:day:love:repeat-day`는 같은 말의 다른 해석을 재진술한다. 서로 다른 관계가 동시에 성립해도 결과 문장 의미가 같으면 하나만 사용한다. 상대의 마음을 사실처럼 말하지 않는 기존 장점은 유지한다.
- **사업**: 0012·0026의 `sector:day:business:output`과 `sector:day:business:detail-04`는 초안 또는 작은 결과로 보여준다는 행동이 같다. 하나만 선택한다. 0030의 detail-02와 mixed-year-month도 답변·결정권 범위의 유사성이 높다.

모든 분야에 반복된 `mixed-year-month` 계열은 일상 조언으로서 무해하지만 정작 어떤 세운과 월운 관계가 그 문단을 선택하게 했는지 사용자가 알기 어렵다. 실제 엔진의 조건을 먼저 확인하고, 참인 경우에만 기간 관계를 상징으로 소개하거나 근거가 불충분하면 본문을 줄이는 편이 낫다. 개별 조건을 확인하지 않은 채 특정 합·충을 새로 주장해서는 안 된다. 특히 기존 핵심이 첫 문단부터 「~하기 좋은 날」이라 쓰더라도 이는 사실 예언이나 점수의 객관적 의미로 받아들여질 수 있다. 0028처럼 관계를 먼저 제시하고 행동은 가능성이나 선택으로 표현하는 방식이 더 명확하다.

## 한계와 후속 확인

본 검토는 현재 선택된 원고에 대한 편집 의견이다. 입력 20개는 표본의 일부이며 대표성이나 전체 콘텐츠 정확성을 보여주지 않는다. 점수 구간과 문장의 충돌은 위 120개에서 명백한 정반대 표현을 발견하지 못했으나 모든 점수 정책의 의미를 독립 검증한 것은 아니다. 원고 수정 후 같은 입력을 다시 돌려 선택 조건·의미 중복과 실제 모바일 화면을 재검토해야 한다. 이 문서는 제안이며 서비스 데이터를 직접 수정하거나 변경을 검증한 기록이 아니다.
