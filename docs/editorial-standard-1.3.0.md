# 한국어 편집 기준과 작업 순서

2026-10-21. 먼저 KR-04를 실제 복사본 CLI에서 재현한 뒤 과거 원문 스냅샷과 명시적 supersedes 이력을 구현한다. 그다음 아래 대표 16개로 문체를 정리하고, 정상210개·공통5개·근거25개·draft4개·13메뉴 화면과 안내를 모두 검토한다. 새 원고 수를 늘리지 않는다.

독자는 20~60대다. 차분한 해요체로 실제 장면을 먼저 쓰고, 긴 명사구와 편집 방법 설명은 줄인다. 단어 치환·어미 교대가 아니라 문장의 뜻을 다시 구성한다. 필요한 명리 용어·한계는 근거에 남긴다. 설명·상황·제안이 다른 역할을 갖도록 하고 모든 문단을 숙제로 끝내지 않는다. 숫자는 실제 도움이 될 때만 쓴다.

종합에서 기본은 생활 습관, 성격은 자신을 평가하는 방식, 직업은 실제 일과 비용, 연애는 개인적인 바람의 전달, 대인관계는 여러 사람의 예절·역할을 맡긴다. 같은 조언에 다른 이름을 붙여 중복을 숨기지 않는다. 선택 조건·우선순위·동수·달력 계산은 바꾸지 않는다.

관계가 필요한 장면은 문단 처음에서 상황을 밝힌다. 현재 교제·혼인·직업·건강·재산을 알았다는 문장을 만들지 않는다. 시범은 계속 draft다. 편집자의 실제 승인이나 명리 검증을 꾸며 쓰지 않는다.
