# 탐색 검토와 개발용 모델 사용 방식

2026-10-31 사용자 요청에 따라 서브에이전트는 Terra high를 사용합니다. 세 역할을 최대 세 개 에이전트로 나누고 재귀 위임은 하지 않습니다. 에이전트는 구체적인 새 과제가 있을 때만 실행합니다.

## 중복을 줄이는 순서

1. 메인이 기준 커밋·기존 미완성 변경·대상 버전·합성 입력·계산 정책을 고정합니다. 재시작하면 저장된 결과와 변경 목록을 읽고 완료한 검사를 새 작업으로 세지 않습니다.
2. 실제 브라우저, 입력 경계, 점수/본문 일치, PDF 포함, 선정 전제, 해시 검사는 스크립트로 실행합니다. 무료 운세에 런타임 LLM을 추가하지 않습니다.
3. 요구사항 담당은 계산과 문장 의미의 차이를, 구현 담당은 지정한 원고 파일의 수정만, 테스트 담당은 새 흐름과 실패 재현을 맡습니다. 파일 소유권이 겹치면 쓰기를 중단하고 메인이 통합합니다.
4. 모델에 이미 읽은 전체 저장소나 대화 기록을 반복 전달하지 않습니다. 합성 사례·새 실패·관련 원고와 조건·변경 전후만 전달합니다. 처음 검토하는 원고의 범위는 별도 목록으로 남깁니다.
5. 독립 초안을 먼저 저장하고 SHA-256을 기록한 뒤 사이트 결과를 엽니다. 뒤에 쓴 공통 사실 기반 초안은 블라인드 결과로 표시하지 않습니다. 사이트와 같은 여섯 분야를 사용합니다.
6. 수정은 작게 묶고, 실제로 바뀐 경로와 연관 회귀를 다시 실행합니다. 최종 통합에서는 필수 전체 검사를 한 번 완료합니다. 통과한 검사를 이유 없이 반복하거나 대기로 시간을 채우지 않습니다.

원고 기준은 [현재 교정 기준](../copy-cleanup/writing-rules.md)을 따릅니다. 계산 사실, 전통적 해석, 생활 제안은 구분합니다. 모델의 기억이나 다수결을 만세력 정답으로 쓰지 않습니다.

## 재현 명령과 범위

- `node --import tsx scripts/exploratory-check.ts`: seed 20261031, 서로 다른 유효 입력 118개와 무효 입력 12개. 선정 조건·동일 입력 재조회·양음력 동치·미확정 처리·저장 원고 소유·분야 지수와 일정 선택의 불변성을 검사합니다. 같은 라이브러리의 왕복 검사를 독립 달력 검증으로 세지 않습니다.
- `python3 scripts/exploratory-independent.py`: 선택 설치한 `sxtwl==2.0.7`, `astronomy-engine==2.1.19` 및 Python `zoneinfo`로 동일 합성 입력의 원국을 대조합니다. 앱의 역법 모듈을 가져오지 않습니다. 한국 음력 판정이나 미래 예측의 정확도를 인증하지 않습니다. 테스트 중 임시 설치 경로는 보고서에 남깁니다.
- `npx vitest run tests/domain/exploratory-content.test.ts`: 다른 종류의 삼합을 잘못 단정하지 않는지, 미상 시각 처리와 공용 상세 원고의 대상 기간을 검사합니다.
- `npx playwright test tests/e2e/exploratory-regressions.spec.ts`: 지정일·선택 연도·서머타임 미확정·지원 마지막 연도 안내를 실제 화면에서 검사합니다.

실제 모델 사용량이나 청구 금액은 이 기록으로 추정하지 않습니다. 개발용 모델 사용, 스크립트 실행, 운영 서비스의 유료 AI API 호출은 구분합니다. 이번 탐색은 운영 AI 생성 API를 호출하지 않습니다.

## 시간과 배포 기록

검토 시간은 진행 기록의 실제 능동 작업 구간만 합산합니다. 사용자의 중단 요청·사용량 제한·다음 날 재개 사이의 경과 시간은 제외합니다. 공개 사이트와 로컬 후보는 구분합니다. 프록시 CONNECT 403이면 토큰 오류나 Cloudflare 응답이라고 단정하지 않습니다. 같은 연결 실패를 반복하거나 TLS 검증을 끄지 않습니다.

기존 미완성 AI·출시 관련 수정은 임의로 커밋하지 않습니다. 수정 원고와 재현 자료는 별도 보관하며 배포에 성공했을 때만 반영됐다고 보고합니다.
