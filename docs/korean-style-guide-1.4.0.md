2026-10-22. 사용자가 확정한 것은 제목의 **상황이나 내용을 바로 알 수 있는 담백한 방향**이다. 이전 비교표의 A 후보 12개를 모두 승인한 것은 아니다. 본문·생활 제안·근거·입력·오류·공유 안내의 교정은 문장별 선택을 다시 요구하지 않고 진행한다.

사용자가 거절한 제목은 “섬세한 기준을 나에게도 다정하게”다. 집안 정리와 휴식의 관계가 드러나지 않는다는 이유와 함께 부정 예시로 남긴다. 이번 제목은 “정리 때문에 쉬는 시간이 늦어질 때”다. 새 형용사를 끼워 넣어 비슷한 표어를 만들지 않는다.

## 적용한 지침과 순서

[DaleSeo/korean-skills](https://github.com/DaleSeo/korean-skills)의 공개 지침을 읽고 한 작업자가 순서대로 적용했다. 별도 설치·자동 활성화·외부 모델 호출·다중 에이전트 실행은 하지 않았다.

1. [humanizer](https://github.com/DaleSeo/korean-skills/blob/main/skills/humanizer/SKILL.md): 제목과 본문을 함께 읽고 실제 상황을 먼저 정리했다. 추상적인 비유, 번역투, 겹친 조건, 같은 내용을 반복하는 문단을 고쳤다. 필요한 참조는 vocabulary-patterns, translation-ese-patterns, structure-patterns다.
2. [grammar-checker](https://github.com/DaleSeo/korean-skills/blob/main/skills/grammar-checker/SKILL.md): rules와 common-errors를 함께 읽고 맞춤법·조사·호응·띄어쓰기와 문맥을 다시 살폈다. “좋은 일이 생겨 만나는 사람에게 연락”처럼 주체와 대상이 뒤바뀌지 않는지도 확인했다.
3. [style-guide](https://github.com/DaleSeo/korean-skills/blob/main/skills/style-guide/SKILL.md): tone-consistency, terminology, numbering-units를 참고해 해요체·용어·숫자·날짜 표기를 확인했다. 공개 근거 정의 25개의 계산 사실은 대응 관계를 그대로 두고 문장 끝만 해요체로 고쳤다.
4. 전체 결과 10개를 조립해 처음부터 끝까지 다시 읽었다. 기존 6개에 병화 종합·월간·일간·일간 미확정 성격을 더했다. 원고 자체의 반복과 계산 범위 안내의 반복을 구별했다. 실제 화면과 실제 브라우저 PDF는 별도로 확인한다.

이 지침의 AI 탐지 등급·자연도 점수·단어 빈도·변경률·문장 길이 분포를 합격 기준으로 쓰지 않았다. 숫자나 근거를 새로 만들어 구체적으로 보이게 하지 않고, 오타나 무작위 어미 변주도 넣지 않았다. 가능성과 불확실성을 단언으로 바꾸는 예시는 적용하지 않는다.

## 문맥에 따라 유지한 표기

- `10개`, `5명`, `10분`처럼 아라비아 숫자에 단위를 붙이는 허용 표기를 오류로 바꾸지 않는다. `할 수 있어요`의 의존명사와 조사의 받침은 따로 확인한다.
- 보조 용언의 허용 표기와 합성 동사를 구별한다. 예를 들어 `해 봐요`와 허용되는 `해봐요`를 이유 없이 전부 오류로 분류하지 않으며, `살펴보다`를 억지로 띄우지 않는다. 참조 문서에 실린 `하고있습니다` 같은 붙임은 따라 쓰지 않는다.
- 명칭이나 같은 묶음의 `직업·재물`, `연·월주` 같은 표기를 단순히 가운뎃점이 있다는 이유로 바꾸지 않는다. 일반 독자가 읽는 긴 나열은 필요하면 문장으로 풀어쓴다.
- 본문은 해요체를 유지한다. 버튼·제목·표의 짧은 명사형, 실제 예문 인용, 출처·라이선스의 고유 표기를 문장으로 억지로 늘리지 않는다.
- 불필요하게 두 개·세 개를 정하게 하던 생활 과제는 필요한 내용 중심으로 고칠 수 있지만, 계산된 글자 수·십성 관계·날짜·시간·출처의 수치는 바꾸지 않는다. 인용 예문은 원문과 다시 대조한다.

## 실제 편집 기준

제목은 어떤 상황이나 내용을 읽을지 알려준다. 본문은 상황, 이유, 제안을 일상에서 쓰는 말로 이어 쓴다. “온기·여백·다정함”을 새 금지어로 만들지 않되, 그 말만으로 내용을 대신하지 않는다. 이미 분명한 “어디까지 하면 끝인지 정해요”, “장난이 다르게 들렸을 때”는 유지한다.

종합의 집안 정리·성격의 실수 뒤 자기평가·직업의 수정 범위와 보수·연애의 바람 전달·대인관계의 말투와 실제 불편은 서로 다른 내용을 맡는다. 조언을 숫자 숙제로 늘리거나 같은 확인을 다른 이름으로 되풀이하지 않는다.

계산 사실 / 상징에 빗댄 내부 해석 / 생활 제안은 구별한다. 현재 교제 여부·직업·수입·건강·상대 마음을 새로 추정하지 않는다. 시간 미상이나 일간 미확정을 채워 넣지 않는다. 오행·천간의 개수를 강약·용신·능력으로 바꾸지 않는다. 안전·실제 생활 문제, 상대의 동의, 구간의 적용 범위처럼 뜻을 정하는 제한은 남긴다.
