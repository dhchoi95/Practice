# 콘텐츠 1.1.0 고도화 결과

2026-10-20. 기준은 첫 커밋 `6f12141`의 콘텐츠 1.0.2입니다. 이번 작업은 사주 주요 메뉴의 원고·근거·적용 조건과 반복 평가 절차를 개선한 안입니다. 운영 배포와 모델 가중치 학습은 실행하지 않았습니다.

분량은 제목·조언·근거 패널을 제외한 원고 본문 문자 수입니다. 숫자가 크다는 이유로 내용이 정확하다고 판단하지 않습니다. 오행 보완 35개와 가벼운 유형 28개 등 기존 75개 원고의 본문은 이번에 다시 작성하지 않았습니다. 기존 독립 검토의 판정을 새 원고의 검토 완료로 확대하지도 않습니다.

기본 원고에서 반복되던 도입과 일간별 공통 관찰 문장을 주제별 상황·선택·실행 방법으로 교체했습니다. 기간 원고에는 하루의 단일 작업, 월간의 주별 점검, 연간의 분기 계획처럼 실제 시간 범위에 맞는 설명을 넣었습니다. 관리을·사이을 같은 조사도 수정하고 검사 용어를 늘렸습니다.

## 같은 일간에서도 다른 설명

단일 일간만으로 결과를 정하던 구조에 이미 계산 중인 확정 천간 관계를 추가로 활용했습니다. 예를 들어 양력 1992-05-15 10:30과 2000-01-04 10:30은 둘 다 신금 일간이지만, 연애 보완 원고는 각각 식상의 표현·전달 질문과 관성의 약속·경계 질문으로 달라집니다. 실제 계산·브라우저 입력으로 확인했습니다.

일간을 제외한 확정 천간에서 확인한 관계만 셉니다. 여러 후보에서는 같은 독점 그룹 안에서 개수가 많은 설명 하나를 우선하고, 동수이면 정해진 ID 순서로 선택합니다. 개수는 원국 전체의 십성 우세나 강약이 아닙니다. 일간이 미확정이면 해당 원고는 제외합니다. 월령·지지·지장간을 계산한 척하지 않습니다.

근거 패널에는 실제 일간 또는 확인된 천간 관계 개수, 그 사실에서 관찰 질문으로 확장한 이유, 적용 범위를 보여줍니다. `evidence.counterExample`도 원고 저장소에 남겨 이후 검토자가 반대 사례를 대조할 수 있게 했습니다.

## 반복 평가에서 확인한 것

새 평가 기준을 이전 1.0.2 원고에도 적용했습니다. 이전 원고는 신규 관계 원고·구조화된 근거 등 새 요구를 충족하지 않으므로 평가 사례 23개 중 12개만 통과했습니다. 고도화안은 23개 모두 통과했습니다. 이것은 새 수용 기준의 충족 여부이며 예측 적중률의 개선 비율을 뜻하지 않습니다.

평가에는 같은 일간의 다른 관계, 미상 시각의 일간 확정/미확정, 0·누락 집계, 일간 없이 관계만 주어진 반례, 개수 우선·동수 선택, 기간 원고와 일간 미확정 안내가 들어 있습니다. 원고 배열을 뒤집어도 결과가 같아야 합니다. 근거를 보장하지 않는 `any` 분기와 잘못된 근거 키·순위 집계도 검사합니다.

기본·기간·관계 원고에서 36자 이상 문장이 세 원고 이상 반복되는 항목은 현재 0개입니다. 원고 계열별 유사 템플릿·선정 조사·근거 연결 검사도 통과했습니다. 이러한 탐지는 전체 한국어 문법·의미·전문 명리 판단을 대신하지 않습니다.

초기 20개 사례 통과 후 일간이 없는데 기간 관계값만 주어진 비정상 입력을 연·월·일 3개로 추가했습니다. 수정 전에는 이 3개가 실패했습니다. 기간 원고 30개에 일간 필수 조건을 추가하고 근거 검증도 보완한 뒤 총 23개로 재평가했습니다. 정상 계산 경로는 원래 미확정 일간의 기간 관계도 null로 만들며, 이번 보완은 잘못된 데이터가 주어진 경우의 방어입니다.

## 실제 검증

- `npm run verify`: ESLint, strict TypeScript, 단위·통합 230개, 콘텐츠 lint·coverage·고정 평가 통과.
- `npm run build`: 콘텐츠 검증·평가 후 정적 export 성공, 생성 작업 36개.
- `npm run test:e2e`: Chromium 57개 통과. 기존 56개와 실제 출생일의 관계 변화 검사 1개.
- `python3 scripts/verify-print-pdfs.py`: 실제 PDF 9개 포함·부재 검사 통과.
- `npm run content:preview`: 63개 합성 프로필 × 사주 10메뉴, 가벼운 유형 28종, 10일간 전체 coverage 실패 0.
- 명시적으로 적은 십성 10×10 대응표와 계산 함수 100조합 일치 검사 통과. 이는 서비스 대응 정책의 검증이며 해석의 과학적 정확성 인증이 아닙니다.

일간이 확정된 합성 프로필의 주제별 결과 본문은 약 777~1,236자입니다. 종합은 요약과 보완을 포함해 1,529~1,781자로 기존 1,800자 상한 안에 있습니다. 일간 미확정 결과는 길이를 채우지 않고 제한 안내를 유지합니다.

화면·계산·개인정보 회귀 검사는 로컬 정적 빌드에서 수행했습니다. 실제 운영 URL·인스타그램 인앱·새 Lighthouse 측정은 이번 작업에서 재검증하지 않았습니다. 현재 홈페이지에 자동 반영한 것도 아닙니다.

현재 근거는 내부 대응 정책과 독립 창작입니다. 외부 원전 인용을 새로 확보하거나 명리 검토자의 확인을 받았다고 표시하지 않습니다. 다음 단계는 출처가 확인된 자료와 검토자의 교정·반례, 사용자가 전달할 실제 문장 지적을 같은 저장소·평가 절차에 연결하는 것입니다.
