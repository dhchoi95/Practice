# 1.0.2 현재 상태와 휴대폰 테스트 준비

2026-10-20. [접수한 독립 검토 현황](external-review-status-1.0.2.md)의 판정은 **공개 가능 — 검토한 기본 기능과 기존 지적 해결 범위**입니다. F-01-R을 포함한 기존 지적은 모두 해소됐고 이번 독립 검토에서 새로 확정한 결함은 없습니다. 현재는 실제 휴대폰 사용자 테스트를 시작할 첫 서비스 버전입니다.

## 확인한 상태

검토받은 1.0.2 스냅샷은 `06a0347e965030d85afdadc6c7a5fd22044905059b9972d8bf960d5b569e3272`입니다. 이번 보고서를 받은 시점에 제출본 manifest와 현재 작업본을 SHA-256으로 대조했습니다. 앱 소스·테스트·스크립트 56개와 정적 빌드 파일 202개를 포함한 제출 프로젝트 파일 290개가 모두 일치했습니다. 이후에는 검토 기록과 안내 문서만 추가·갱신했습니다. 앱 코드와 콘텐츠, 검토받은 정적 빌드는 바꾸지 않았습니다.

단위·통합 192개, 브라우저 56개, 실제 PDF 9개 검사는 이전 구현 검증과 이번 독립 검토에서 각각 수행됐습니다. 독립 검토자는 별도 6개 시나리오와 PDF도 확인했다고 보고했습니다. 이번 접수 작업에서 검사를 새로 실행했다는 뜻은 아닙니다. 독립 검토의 전체 `npm run verify`는 tsx IPC 권한 오류로 중단됐고, 콘텐츠 검사는 문서의 대체 명령으로 각각 통과한 결과임을 구분합니다.

## 바로 사용할 산출물

`/workspace/release-1.0.2/haru-saju-1.0.2-static.zip`은 검토받은 `out/`의 202개 파일만 담은 정적 호스팅 업로드용입니다. 압축 최상위에 `index.html`, `404.html`, `_next/`, `fortune/`, `result/` 등이 있습니다. 원고·코드·검토 자료를 모두 담은 이전 재검토 ZIP과 용도가 다릅니다. 검토받은 빌드와 각 파일이 같은지는 별도 `static-manifest.json`에 기록합니다.

정적 호스팅에 이 파일들을 문서 루트로 올리면 Node·Python·DB·AI API 키 없이 휴대폰 브라우저로 이용할 수 있습니다. 정확한 경로의 `index.html`을 제공하고 없는 경로는 실제 404를 반환해야 합니다. 모든 경로를 홈으로 돌리는 SPA 재작성은 필요하지 않습니다.

현재 빌드는 운영 도메인이 미설정인 검토용 빌드이며 canonical은 생략하고 sitemap은 빈 목록입니다. 실제 운영 도메인을 정한 공개용 빌드는 [배포 안내](deployment.md)에 따라 URL·운영 고지를 반영해 다시 만듭니다.

## 남은 실제 작업

1. 테스트 호스팅의 계정·배포 대상을 정하고 HTTPS 접속 주소를 발급합니다. 본인 전용 테스트에는 호스팅의 접근 제한을 설정해야 하며 ZIP 자체가 접근 제한을 제공하지는 않습니다.
2. 휴대폰의 일반 브라우저와 인스타그램 인앱 브라우저에서 입력 → 결과 → 수정 → 다른 풀이를 확인합니다. 시간 모름·음력/윤달, 공유·복사·취소, 새로고침·삭제, 큰 글자·회전·키보드 상태도 확인합니다.
3. 일반 공개 전에 서비스명·운영 연락처·호스팅 로그 안내·운영 URL을 정리합니다.

아직 실제 접속 주소는 없습니다. 외부 호스팅 생성·배포·계정 변경·GitHub push는 이번 작업에서 실행하지 않았습니다. 실제 인앱·OS 인쇄 UI·공개 호스팅·새 Lighthouse 측정과 명리 전문가 인증의 미확인 범위는 원본 검토 보고서에 남아 있습니다.
