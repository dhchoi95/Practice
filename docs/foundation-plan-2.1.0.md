# 2.1.0 실행 계획

기준 커밋 287364976778081c8b68a867633159558c5b45bb. 현재 작업 트리는 깨끗하며 첨부 2.0.0과 같은 기준이다. 첨부 지시문 전체를 읽었다. 현재 Node·잠금 의존성과 Chromium을 재사용하며 새 설치·독립 승인으로 보고하지 않는다.

1. 기존 역법·시간 보정·대운 계산 재사용. 기준표를 ID로 정규화하고 분야별 판단 스키마를 추가한다.
2. 조건부 중심 원고, 원국·기간 보완, 지정일 일정 원고를 집필한다. 기간 변형과 독립 의미 수를 구분한다.
3. 동일 판단에서 지수·본문·근거를 만든다. 연간은 12개월의 실제 절입·대운 구간을 합쳐 길이 가중 집계한다.
4. 시·일·월·년 순서의 접근 가능한 원국표를 항상 표시한다. 날짜를 바꿔도 원국은 고정한다.
5. 오늘·내일·지정일·월·연의 여섯 분야 화면, 정통사주 재배치, 독립 만세력, 홈페이지 메뉴를 연결한다.
6. 기존 회귀와 새 의미 검사, 12명 이상 365일·12개월·5년, 실제 읽기 9개 이상, 모바일·확대·PDF·개인정보 검사를 수행한다.
7. 변경·원고 집계·실패/재검사·출처 대기 항목과 재현 자료를 검토 ZIP으로 전달한다. 원격 push·공개 배포는 하지 않는다.

옛 UI가 바뀌는 회귀 검사는 새로운 인수 조건으로 명시적으로 갱신한다. 기존 계산·콘텐츠·검토 이력은 삭제하지 않는다. 巳 보조 지장간 순서·도시 좌표·강약 독립 검토는 계속 대기 상태다.
