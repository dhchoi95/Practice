# 화면 가이드

하루사주는 흰 바탕의 한국어 운세 포털입니다. 큰 홍보 화면 대신 상단 분류·짙은 4×2 바로가기·3×3 타일을 먼저 보여줍니다. 참고 이미지가 없어 첨부 문서의 묘사를 기준으로 독립적인 배치와 SVG를 제작했습니다.

색은 `styles/tokens.css`에서 바꿉니다. 배경 #FAF9F6, 본문 #282722, 보조 #625F58, 강조 #8D3430, 내비 #303641, 보조 초록 #3D6555입니다. 금색은 장식과 배경에 제한합니다. 버튼·링크·포커스는 색 외에 테두리·밑줄·굵기로도 구분합니다. 실제 Chromium의 axe WCAG AA 대비 검사로 확인합니다.

모바일 본문은 16px, 결과는 17px/1.9 행간입니다. 일반 제목은 23~29px, 결과 제목은 명조 계열을 제한적으로 사용합니다. 긴 본문은 운영체제 한국어 산세리프입니다. 외부 웹폰트 요청은 없습니다.

별자리 선택의 기준 날짜는 14px 이상이며 2열로 표시합니다. 280px 이하에서는 1열로 바꾸어 날짜와 라디오가 겹치지 않게 합니다. 195·320·390px과 날짜 글자 200% 확대에서도 선택·제출과 넘침을 검사합니다.

전체 최대 폭은 1080px, 결과·입력은 740px입니다. 모바일 좌우 16px, 타일 간격 9px, 본문 패널은 약 20px 안쪽 여백을 둡니다. 표의 열은 연·월·일·시 순서로 고정합니다. 일간과 실제 알려진 글자 수를 텍스트로 설명합니다.

375·390·1440px의 홈·입력·결과를 `reports/screenshots/`에 캡처합니다. 320·360·375·390·430·768·1024·1440px에서는 가로 넘침을 검사합니다. 200% 확대에 대응하는 좁은 레이아웃에서는 2열·줄바꿈을 허용합니다. 자동 다크모드는 없고 reduce-motion 설정을 존중합니다.

SVG는 `components/Illustration.tsx`에 있으며 장식으로 `aria-hidden` 처리합니다. 경쟁사 자산·외부 핫링크·그림 속 제목은 사용하지 않습니다. 실제 서비스명은 `config/site.ts` 한 곳에서 변경하며 브랜드의 日 표시는 직접 그린 장식입니다.
