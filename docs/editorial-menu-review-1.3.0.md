홈의 연간 배너는 미래를 미리 본다는 말보다 계획을 돌아보는 말로 고쳤다. 입력의 양력/음력/윤달/시간 미상/표준시 안내는 이미 명확해 대체로 유지했다. 오류의 어색한 표현만 고쳤으며 동작은 바꾸지 않았다. 새로고침·다른 사람·삭제·공유의 일반 메뉴 링크·인쇄의 개인정보 안내는 실제 동작과 맞아 유지했다.

공통5개와 근거25개는 언어·값·한계를 대조했다. 출처/소개 페이지는 라이선스·실제 확인 범위를 훼손하지 않고 일부 설명만 쉽게 썼다. glossary와 날짜별 가벼운 조언7개는 필요한 정의/짧은 장면이어서 유지했다. 별도 초안4개는 문장만 편집하고 조건·다중 전제·draft 상태·일반 fallback을 유지했다.
