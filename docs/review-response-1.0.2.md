# 1.0.1 재검토 잔여 지적 수정 — 1.0.2

2026-10-20. [접수한 재검토 보고서](external-rereview-1.0.1.md)와 증거 ZIP을 읽고 해시를 대조했습니다. 현재 작업본이 검토받은 스냅샷 `09406e7926e90657f0aaf0ba6cf74965ac171ed62bc75d264ff8ff7b8b89458a`의 소스와 같음을 수정 전에 확인했습니다.

외부 재검토에서는 F-02~F-06 해소, F-01의 주요 본문 해소와 기간 상세의 P2 잔여 문제 F-01-R을 보고했습니다. 이번 작업은 그 잔여 문제에 대한 구현자의 수정·검증 기록입니다. 독립 재검토의 최종 통과 판정을 대신하지 않습니다.

## 변경 내용

`src/components/FortuneResult.tsx`에서 일간 확정 여부에 따라 기간 상세 도입 문장을 나눴습니다.

| 입력 상태 | 연·월·일 기간 상세와 인쇄물의 안내 |
|---|---|
| 일간 미확정 | “일간이 미확정이라 나의 일간과 기간 간지의 관계는 해석하지 않았어요. 아래에는 대상 기간의 간지와 경계만 표시해요.” 기간별 관계값은 미확정으로 남습니다. |
| 일간 확정 | 기존 “내 일간과의 관계를 살폈어요” 안내를 유지합니다. 연간·월간의 실제 구간 풀이 요약 안내도 유지합니다. |

미확정 입력에는 관계를 분석했다거나 구간별 풀이를 요약했다는 문장을 출력하지 않습니다. 기간의 날짜 경계와 간지 표시는 계속 제공됩니다. 사이트 설명 버전을 1.0.2로 올렸으며 원고 레코드의 버전과 내용은 그대로입니다.

## 수정 전 실패와 수정 후 검사

`tests/e2e/site.spec.ts`에 연·월·일 × 일간 확정/미확정의 6개 회귀 검사를 추가했습니다. 기기 날짜는 2026-12-31로 고정하고 다음 두 합성 입력을 사용합니다.

- 미확정: 양력 1987-06-01, 시간 모름.
- 확정: 양력 1992-05-15, 10:30.

각 검사에서 상세가 모두 닫힌 기본 상태로 실제 PDF를 만들고, 인쇄 후 닫힘 상태가 복원되는지 확인합니다. 이어 기간 상세를 펼쳐 안내와 관계값을 함께 검사하고 화면을 캡처합니다. `scripts/verify-print-pdfs.py`는 실제 PDF 텍스트에서 필요한 문구의 포함과 잘못된 주장의 부재를 검사합니다.

| 실행 | 실제 결과 |
|---|---|
| 수정 전 새 브라우저 회귀 6개 | 미확정 연·월·일 3개 실패, 확정 입력 3개 통과 |
| 수정 전 실제 PDF | 미확정 3개 모두 관계값 미확정과 관계 분석 주장이 함께 존재. 연간·월간에는 구간 요약 주장도 존재 |
| `npm run verify` | ESLint·strict TypeScript·단위/통합 192개·콘텐츠 lint·coverage 통과, 종료 코드 0 |
| `npm run build` | 콘텐츠 validate 및 정적 export 성공, 생성 작업 36개, 종료 코드 0 |
| `npm run test:e2e` | 기존 50개와 새 6개, 총 56개 통과. 실패/skip 없음 |
| `npm run content:preview` | 합성 입력 미리보기 갱신 성공 |
| `python3 scripts/verify-print-pdfs.py` | 실제 PDF 9개 포함·부재 검사 통과. 기존 정통사주 닫힘/열림 출력 텍스트 동일 |

PDF 9개는 기존 정통사주 2개·연말 경계 1개와 새 기간 6개입니다. 새 미확정 연·월·일은 각각 2쪽, 확정 연·월은 각각 3쪽, 확정 일간은 2쪽입니다. 펼친 상세와 실제 PDF를 직접 열어 새 안내가 읽히는 것도 확인했습니다.

이번 환경은 Linux, Node 24.19.0 / npm 11.9.0 / 시스템 Chromium 151 / Playwright 1.64.1입니다. 외부 검토자의 Chromium 153 실행 결과와 이번 실행을 구분합니다. 검사 도중 이전 소스를 `.tsx` 복사본으로 reports에 보관해 TypeScript가 읽는 작업상 오류가 한 번 있었습니다. 복사본을 `.tsx.txt`로 정리하고 전체 verify와 빌드를 다시 실행해 통과했습니다. 실패 로그도 별도 보존했습니다.

## 계산·콘텐츠 변경 범위와 남은 제한

검토받은 1.0.1 manifest와 SHA-256을 비교해 도메인 로직, 전체 원고와 공통 설명, 계산 fixture, package.json과 lockfile 등 23개 파일이 그대로임을 확인했습니다. 달력·시간대·원국·기간 계산이나 원고 180개/공통 설명 5개를 다시 작성하지 않았습니다. 자동 검사 상태를 전문가 검토 완료로 바꾸지도 않았습니다.

접수한 ZIP의 증거 index에 기록된 해시를 확인했고, 내부 보고서가 별도 첨부 보고서와 같은 것도 확인했습니다. 검토자의 KASI 보존 자료 59행 재대조 결과는 외부 검토 근거입니다. 원자료 59행은 이번 ZIP에 없으므로 구현자가 동일 자료를 재실행했다고 표시하지 않습니다. 이번에는 기존 29개 ICU 날짜·72절입·보고서 전사 3개 KASI 날짜와 정책 회귀 검사를 실행했습니다.

새 Lighthouse 측정, 실제 iOS/Android 인스타그램 인앱 브라우저, OS 인쇄 대화상자, 물리 프린터, Safari/Firefox 인쇄, 공개 호스팅은 실행하지 않았습니다. 공개 배포·GitHub push·외부 메시지 전송도 하지 않았습니다.
