# 콘텐츠 변경 기록

## 1.0.2 — 2026-10-20

- F-01-R: 연·월·일 기간 상세 안내를 일간 확정 여부로 나눴습니다. 미확정이면 개인 일간과의 관계를 해석하지 않았으며 기간 간지·경계만 표시한다고 안내합니다. 구간 해석을 요약했다는 문장도 제외합니다.
- 펼친 상세와 실제 PDF의 일간 확정/미확정 6개 조합에 회귀 검사를 추가했습니다. PDF 텍스트 검사는 기존 3개에서 9개로 확대했습니다.
- 사이트의 설명 릴리스는 1.0.2입니다. 기존 원고 180개·공통 설명 5개와 각 레코드 버전, 달력·시간대·원국·기간 계산 정책은 이번 수정에서 변경하지 않았습니다.

## 1.0.1 — 2026-10-20

- 오행 보완 35개를 주제별 상황·관찰·행동으로 다시 작성하고 공통 오행 설명 5개를 별도 저장했습니다. 총 조건별 원고 수는 180개이며 공통 설명을 더해 185개 해석이라고 세지 않습니다.
- 일간을 전제하는 시간 미상 원고 3개에 `natal.dayStem` 의존성을 추가했습니다. 일간 미확정에는 별도의 중립 안내를 보여줍니다.
- 선정한 오행·십성 조사 오류를 원고 전반에서 수정했습니다. 주제명 치환·유사 템플릿·조사 회귀 검사를 추가했습니다.
- 자동 검사 상태를 유지합니다. 독립 명리·한국어 편집 검토 완료를 뜻하지 않습니다.

## 1.0.0 — 2026-10-20

- 10일간 × 7 주제 70개, 오행 집계 보완 35개, 기간 십성 30개, 가벼운 유형 28개, 시간 미상·관계·집계 안내 17개를 작성했습니다. 이후 독립 검토에서 오행 보완의 반복과 조건 누락 등이 발견되어 1.0.1에서 수정했습니다.
- 총 180개 레코드와 날짜별 편집 조언 7개를 준비했습니다.
- 원고는 automated-checked 상태입니다. 인간 또는 독립 명리 전문가의 검토 완료로 표기하지 않습니다.
- 기본 성향과 기간 조언·가벼운 읽을거리를 분리했습니다.
