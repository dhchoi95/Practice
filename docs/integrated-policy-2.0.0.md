# 계산·판단·조립 정책 2.0.0

2026-10-22. 기존 1.4.0의 한국어 원고 210개와 표준시 엔진은 호환 모드로 보존한다. 새 계산은 `KR-SOLAR-MIDNIGHT-1.0`, 명리 판단은 `SEASON-ROOT-CANDIDATES-1.0`, 새 콘텐츠는 `2.0.0`이다. 과거 원고를 새 버전으로 일괄 변경하지 않는다. 기존 규칙 엔진 2.0.0과 새 콘텐츠 버전 2.0.0은 다른 값이다.

## 시각과 좌표

- 한국 시계 → IANA Asia/Seoul의 유효 UTC 순간 → UTC+9 표준시 → 선택한 명리 시각 순서다. 기존 gap/fold 거부, 한국 음력·윤달 검증을 그대로 이용한다.
- 지방평균태양시 보정은 `4 × (경도 − 135)`분이다. 진태양시는 여기에 균시차 E를 더한다. E는 겉보기 태양시에서 평균태양시를 뺀 값이며 양수이면 더한다.
- 짧은 NOAA 형태의 근사식: `γ=2π/365 × (UTC 연초부터 지난 날 − 0.5)`, `E=229.18 × (0.000075+0.001868cosγ−0.032077sinγ−0.014615cos2γ−0.040849sin2γ)`분. 365 분모를 윤년에도 유지하는 근사다. 원문 PDF는 접근 차단으로 대조 대기다. 수식이 원문과 완전히 같다고 인증하지 않는다.
- 별도 astronomy-engine의 태양 시각과 6개 연도 각 365일을 비교한 관측 오차는 보고서에 있다. 이 표본의 오차와 모든 날짜의 정확도 보증은 다르다. 천문 절입 비교의 기존 허용치는 90초다.
- 출생 일주·시주는 보정된 시각의 0시 날짜와 같은 날 일간을 쓴다. 23시에도 다음 날 일간을 쓰지 않는다. 연·월주와 대운 절입 차이는 보정 전 실제 UTC 순간을 사용한다. 절입 순간 자체를 도시별로 이동하지 않는다.
- 기간 조회는 한국 표준시의 양력 구간과 일진을 사용한다. 출생 도시를 현재 조회 지역으로 간주하지 않는다. 출생 태양시 정책과 기간 표준시 정책의 적용 대상을 구별한다.
- 도시 12개는 0.01°로 반올림한 중심 편집 좌표다. 외부 지리 자료 검증 대기이며 정확한 주소를 대표하지 않는다. 출처 확인 완료를 꾸미지 않는다. 경기도는 수원으로 대입하지 않는다. 미선택이면 요청한 태양시와 실제 적용한 표준시를 구분해 표시한다.
- 시간 미상 태양시는 가능한 시계의 모든 분과 절입 양쪽을 검사해 공통 기둥만 남긴다. 날짜·일간이 달라질 수 있으면 일간도 null이다. 실제 출생 시각을 임의로 선택하지 않는다. 시각·도시가 없으면 정밀한 태양시 비교와 대운 개시일을 만들지 않는다.

## 지장간과 관계

`mappings.ts`의 표 하나를 천간·본기·전체 지장간 십신과 통근·투출에 함께 쓴다. 본기·중기·여기는 고정 대응 순서이며 절기 안의 사령 일수는 계산하지 않는다. 子=癸, 亥=壬·甲, 未=己·丁·乙이다. 설치한 lunar-typescript 대응표와 비교했지만 본기와 구성 글자는 소프트웨어 표와 같지만 巳의 보조 순서는 서비스 丙·戊·庚, 소프트웨어 丙·庚·戊로 다르다. 서비스는 선언한 고정 순서에서 戊에 0.3, 庚에 0.1을 쓰며 이 본·중·여기 순서의 원전 검토는 대기다. 소프트웨어 배열 자체가 중기·여기의 정답이라는 주장도 하지 않는다. 순서를 바꾸면 해당 강약 후보 점수도 달라질 수 있다. 소프트웨어 구성의 일치를 고전·세부 순서의 독립 검증으로 부르지 않는다.

천간 오합, 지지 육합·충·형(두 글자 후보)·자형·해·파·삼합·방합을 지원한다. 자리별 중복을 남기되 같은 삼합·방합 집합은 한 번만 센다. 출현, 후보, 작동 지지 조건 일부 확인을 구별한다. 삼합·방합에서 같은 오행의 투출·월지 본기·충 방해를 살피지만 **합화는 항상 미확정**이며 다른 오행을 삭제하거나 바꾸지 않는다. 방해 후보와 양립하는 관계도 함께 표시하고 길흉 점수를 합산하지 않는다.

## 강약·격국·용신 후보

정밀한 여러 학파를 혼합해 공인 결론을 냈다고 주장하지 않는다. 이 서비스의 보수적인 본기·계절·통근 편집 판단식 하나를 공개한다. 고전 원문과 독립 전문가 검토가 대기 중이므로 후보이며 특수격·종격은 제외한다.

전체 네 기둥이 확정돼야 강약과 격국에 의존하는 원고를 선택한다. 월지 본기 오행을 큰 계절 대표로 사용한다. 일간 오행이 월지 본기 오행과 같으면 +3, 본기가 일간을 생하면 +2, 일간이 본기를 생하면 −1, 일간이 본기를 극하면 −2, 본기가 일간을 극하면 −3이다. 전통의 旺相休囚死 전체를 정밀 재현한 점수라고 부르지 않는다.

일간과 같은 오행의 뿌리는 본기 +2, 나머지 +1이다. 다른 천간은 같은 오행·인성이면 +1.5, 나머지 −1이다. 지장간은 같은 오행·인성 +, 나머지 −로 본기 0.6/중기 0.3/여기 0.1을 더한다. 지장간 수가 적어도 빠진 가중치를 다른 글자에 재분배하지 않는다. 뿌리와 생조는 별도 채택 요소라 같은 글자가 두 기준에 영향을 준다. 합화는 확정하지 않아 변환 가중치는 0이다. 충 후보는 반대 근거에 남기며 근거 없이 수치 감쇠하지 않는다.

총점 ≥5는 신강 경향, ≤0은 신약 경향, 사이면 중화·경계다. 이 수는 에너지·확률·우열이 아니며 화면에 막대로 포장하지 않는다. 소수 첫째 자리 반올림이다. 주요 요소별 수와 반대 근거를 표시한다. 시주·일간·월지가 없으면 전체 판단값은 null이며 0으로 채우지 않는다.

격국은 월지 본기 십신과 같은 지장간의 투출 여부를 기록한다. 비견은 건록 계열, 겁재는 월겁 계열, 나머지는 해당 십신 중심 후보다. 사령·격의 성패·양인 세부 예외는 유보한다. 식신생재 후보는 천간의 식신·재성·일간 뿌리, 제살 흐름 후보는 천간의 식신·편관·천간 편인 부재를 검사한다. 지장간의 편인·뿌리 강도·직접 작용 등 미확인 조건이 있어 완전한 구조·격으로 확정하지 않는다.

억부는 신강 후보에서 식상→재성, 신약 후보에서 인성→같은 오행을 우선·함께 살필 후보로 둔다. 경계면 강제 선택하지 않는다. 희신은 같은 억부 목적 안의 다음 후보이며 반대 조건을 함께 적는다. 조후는 겨울 亥子丑의 화, 여름 巳午未의 수를 한난 완화 후보로 따로 두고 나머지·습조 세부는 유보한다. 두 목적의 후보를 하나의 정답으로 합치지 않는다.

## 대운

양년 남성·음년 여성 분류는 순행, 반대는 역행이다. 미선택이면 두 후보를 구분하고 한쪽을 추측하지 않는다. 분류를 성격이나 관계 선호로 확대하지 않는다.

순행은 다음 12절, 역행은 이전 12절을 쓴다. 출생 순간과 절이 정확히 같으면 양쪽 모두 차이 0이다. 월주는 같은 실제 순간으로 이미 결정된 기둥에서 첫 대운을 ±1 진행한다. 절기 시계 원자료는 UTC+8이며 UTC 순간으로 환산한 뒤 차이를 낸다.

삼일일세 환산은 실제 시간차에 120을 곱한 상징 시간으로 바꾼다. 360일=1환산년, 30일=1환산월로 분해하고 초 이하도 마지막 밀리초 반올림까지 보존한다. 환산 연·월은 출생 표준시 날짜에 그레고리력으로 가산하고 월말은 마지막 날로 고정한다. 남은 일·시간은 실제 시간으로 가산한다. 달력 가산 정책 차이로 타 만세력의 시작일과 다를 수 있다.

개시일부터 10년씩 10개 구간을 제공한다. 각 구간은 시작 포함·종료 제외이며 현재 구간은 선택 조회일 한국 정오의 실제 순간으로 판정한다. 개시 전이나 제공한 10개 구간 밖을 표시하고 첫·마지막 구간으로 강제하지 않는다. 대운 간지 자체는 2050년 뒤도 표시할 수 있지만 기간 운세 조회는 2050년까지다.

## 기간·원고·실제 표시

연간은 원국·해당 구간 대운·세운, 월간은 월운, 일간은 일진을 추가한다. 양력 연간은 입춘과 대운 전환, 월간·일간은 그 안의 12절과 대운 전환을 경계로 나눈다. 구간의 시작 순간을 포함하므로 같은 날 절입 전후를 구분한다. 같은 양력 연도·월을 조회할 때 날짜나 현재 시간이 바뀌어도 전체 해석은 같다. 기본 오늘/이번 달/올해는 한국시간 날짜를 따라가고, 직접 고른 조회일과 5년 시작 연도는 사용자가 다시 바꾸기 전까지 고정한다.

원국↔기간의 전제와 기간↔기간 관계를 구별한다. `cross.*` 원고는 실제 원국 자리를 포함한 관계만 쓴다. 원국·대운·세운·월운·일진의 실제 위치는 모든 관계에 남긴다. 순역 미선택일 때 두 후보 대운을 하나의 확정 원국에 합산하지 않고 기간 공통 해석에서 제외한다.

새 원고는 `modules.ts`의 명시적 all 전제와 requires, 제외, 우선순위, 역할 독점 그룹을 가진다. any는 이 새 간소 schema에 없고 기존 엔진의 any 함의 검사는 유지한다. 더 구체적인 원고를 우선하고 같은 역할의 동률은 관련 십신 수, 마지막은 고정 ID로 정한다. 이 선정 수는 강약 점수와 다르다. 무관한 feature·난수·방문 기록은 쓰지 않는다.

기간의 같은 원고는 처음 표시한 구간만 본문·제안을 싣고 이후 구간은 실제 참조를 표시한다. `display` 이력은 실제 문단 인덱스·제안·주장과 참조 구간을 구별한다. 길이 제한으로 뒤 항목을 자르지 않는다. 한국어 편집·의미 검토는 자동 중복 검사와 별개다.

## 개인정보와 검토

도시·시각 정책·순역 분류는 기존 BirthSession의 input 안에 추가하고 브라우저 메모리만 쓴다. 기존 calculateSaju·strict validation에는 새 옵션을 제거한 원래 입력만 전달한다. 서버 요청·URL·콘솔·영속 저장·개인 해시를 추가하지 않는다. 공유는 일반 메뉴 링크다. 사용자 입력이 인쇄물에는 들어간다는 기존 안내를 유지한다.

기존 검토 687개와 원문 스냅샷은 바이트까지 보존한다. 새 schema의 원고·주장은 별도 append-only ledger와 스냅샷에서 소유·해시·supersedes를 확인한다. 이전 집필 중 고친 기록도 남긴다. 작성자 기록만 있으며 독립 편집·명리 승인을 부여하지 않는다. 공통 설명으로 합친 옛 격국 9개 기록은 역사 자료이고 현재 활성 원고로 세지 않는다.
