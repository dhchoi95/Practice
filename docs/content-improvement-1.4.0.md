# 콘텐츠 1.4.0 교정 결과

2026-10-22. 사용자가 고른 것은 제목을 담백하게 쓰는 방향이다. 이전 표의 A 후보를 일괄 승인한 것으로 처리하지 않았다. korean-skills의 humanizer → grammar-checker → style-guide를 실제 지침과 필요한 참조 문서를 읽고 순서대로 적용했다. [적용 기준](korean-style-guide-1.4.0.md)에 범위와 문맥상 예외를 기록했다.

정상 원고 210개를 검토해 196개에서 필요한 필드를 고치고 14개는 그대로 두었다. 제목 187개, 본문 155개, 생활 제안 38개, 근거 72개가 바뀌었으며 같은 원고가 중복될 수 있으므로 합산하지 않는다. 별도 초안 4개는 계속 draft이며 일반 빌드에 넣지 않았다. 공통 오행 설명 5개는 유지했고 근거 정의 25개는 계산 대응을 유지하면서 문장 끝만 해요체로 바꿨다.

입력·공유·홈·메뉴·기간 제목·안내 문구도 검토했다. 58개의 실제 교정 기록을 별도로 남겼다. 이미 명확한 오류 안내·인쇄 버튼·사주표·용어 설명을 억지로 바꾸지 않았다. 앱 실행 중 외부 교정기나 모델을 부르지 않는다.

## 보존과 검증

계산·선정·개인정보 처리의 핵심 소스 13개는 기준 해시와 같다. 모든 원고의 ID·조건·requires·exclusions·우선순위·동수·출처·reviewStatus·계산 전제는 유지했다. 바뀐 원고만 1.4.0 또는 1.4.0-draft.1로 기록했다. 유지한 14개에는 버전이나 새 검토를 꾸며 넣지 않았다. 과거 검토 483개와 작업 중 후속 기록도 그대로 보존하고 현재 원문의 해시로 이어갔다.

최종 실행 로그는 reports/content-improvement-1.4.0에 있다. lint·TypeScript·단위/통합 296개, 기존 수용 사례 29개, 63개 합성 프로필의 10개 사주 메뉴와 가벼운 유형 28개, 검토 이력, 10개 조립 결과, 초안 제외, 정적 빌드와 브라우저·실제 PDF 회귀를 실행해 모두 통과했다. 브라우저 63개와 실제 PDF 13개 검사가 통과했고, 정적 산출물은 202개이며 초안 유출은 0개였다. 테스트의 옛 기대 문구는 같은 의미의 새 표현으로 갱신했으며, 거절된 제목의 재등장 금지 검사를 추가했다. 개인정보 비전송·윤달·DST·미확정·선정·인쇄 상태 검사는 유지했다. 최종 성공 수와 명령 결과는 checks.json과 원본 로그를 따른다.

## 남은 확인

독립 한국어 편집자·명리 전문가의 승인은 대기 상태다. 실제 스마트폰·인스타그램 인앱·운영 URL의 새 버전 반영은 로컬 화면/PDF 검사와 별개다. 원격 기본 브랜치가 이 사주 사이트와 다른 음식점 앱이므로 사주 수정본을 별도 브랜치로 푸시하고, 실제 Cloudflare 연결 대상은 확인해야 한다. 공개 서버 반영을 확인하기 전에는 배포 완료로 표시하지 않는다.
