# 2.4.1 문장·분야 구분 후속 교정

2026-10-26: **공개 배포와 공개 주소 검증 완료**

https://spring-voice-4bdc.eogjs9595.workers.dev/

직전 2.4.0 로컬 수정과 이번 후속 교정을 함께 반영했습니다. 앞선 보고서의 미배포 표시는 당시 상태이며, 현재 배포 상태는 이 문서와 `deployment.json`을 기준으로 확인합니다.

사용자가 지적한 문장 오류 8개, 월간 연결 문장 자동 반복, 여섯 분야 내용의 편중을 수정했습니다.

- 실제 교정: 직전 로컬안 대비 기존 사주 원고 8개, 분야 원고 129개, MBTI 원고 3개, 총 140개. 건강 분야 90개는 전체를 생활·휴식 관점으로 교정했습니다.
- 전체 점검: 현재 원고·설명 저장소 1,195개와 공개 코드 35개 파일의 문자열. 초안·내부 원고도 목록에 포함됩니다. 과거 검토 스냅샷과 보고서 인용문은 역사 기록으로 보존합니다.
- 자동 연결 문장: 단어를 바꾸거나 무작위로 돌려 쓰지 않고 원고 조립 시 덧붙이는 기능을 제거했습니다. 본문은 실제 저장된 문단이며 적용 시기는 내부 기록에 남아 있습니다.
- 계산·선정·점수: 기존 엔진 파일과 원고의 비문장 필드를 대조해 보존했습니다. 검토 이력은 현재 해시를 추가하고 이전 기록을 유지했습니다.
- 이후 집필 기준: [분야별 기준](domain-matrix.md)과 [공통 집필 규칙](../copy-cleanup/writing-rules.md)에 반영했습니다. `npm run verify`에 전체 원고 검사와 조립 문장 검사도 연결했습니다.

[실제 수정 전후](before-after.md) · [2027년 여섯 분야 전체 예문](profile-1-year.md) · [월간 전체 예문](profile-1-month.md)

자동 검사는 알려진 문법 오류·동일 문장·원고 연결과 해시를 확인하는 장치입니다. 모든 문장의 자연스러움이나 명리학적 정확성을 인증하는 점수가 아닙니다. 이번 결과는 작성자 검토이며 독립 전문가 검토를 마쳤다고 표시하지 않습니다.

## 최종 검증과 배포

- `npm run verify`: 타입·린트, 단위/통합 413개, 편집 도구 5개 검사와 콘텐츠 검사 통과. 고정 집단의 선정 결과 33,564건 회귀 검사 유지.
- 현재 저장소 원고·설명 1,195개(초안·내부 원고 포함), 공개 코드 35개 파일 검사. 이번 차수에서 직접 교정한 원고는 140개이며, 전체를 새로 집필했다는 뜻은 아닙니다.
- 일·월·연의 조립 결과 15건 생성. 특히 사용자가 지적한 출생정보의 성격풀이, 월간 반복, 2027년 분야별 본문을 실제 화면·인쇄물로 대조했습니다.
- Chromium 브라우저 94개와 실제 PDF 39개 검사 통과. 화면에서 출력한 본문과 PDF를 대조하고, 제거한 구간·설정 UI가 다시 나타나지 않는지 확인했습니다.
- 정적 빌드 성공. Cloudflare Worker에 올린 뒤 공개 주소에서 320px·390px 검증 통과. 성격풀이 오류 재현 입력, 연간·월간·오늘의 실제 여섯 분야 문단·점수가 로컬 검증본과 일치했습니다.
- 원국 유지, 지정일 선택, 만세력, 메뉴 구성, 출생정보 미전송도 공개 화면에서 확인했습니다. 네이티브 인스타그램/카카오 인앱 브라우저 및 실물 iOS/Android 기기는 이번에도 미검증입니다.

검사 로그·현재 화면·PDF는 `reports/copy-followup/`에 있습니다. 과거 검토 자료에 남은 잘못된 문구는 수정 전 원문의 증거로 보존했으며 현재 사용자 원고로 제공하지 않습니다.
