# 2.4.1 문장·분야 구분 후속 교정

사용자가 지적한 문장 오류 8개, 월간 연결 문장 자동 반복, 여섯 분야 내용의 편중을 수정했습니다.

- 실제 교정: 직전 로컬안 대비 기존 사주 원고 8개, 분야 원고 129개, MBTI 원고 3개, 총 140개. 건강 분야 90개는 전체를 생활·휴식 관점으로 교정했습니다.
- 전체 점검: 현재 원고·설명 저장소 1,195개와 공개 코드 35개 파일의 문자열. 초안·내부 원고도 목록에 포함됩니다. 과거 검토 스냅샷과 보고서 인용문은 역사 기록으로 보존합니다.
- 자동 연결 문장: 단어를 바꾸거나 무작위로 돌려 쓰지 않고 원고 조립 시 덧붙이는 기능을 제거했습니다. 본문은 실제 저장된 문단이며 적용 시기는 내부 기록에 남아 있습니다.
- 계산·선정·점수: 기존 엔진 파일과 원고의 비문장 필드를 대조해 보존했습니다. 검토 이력은 현재 해시를 추가하고 이전 기록을 유지했습니다.
- 이후 집필 기준: [분야별 기준](domain-matrix.md)과 [공통 집필 규칙](../copy-cleanup/writing-rules.md)에 반영했습니다. `npm run verify`에 전체 원고 검사와 조립 문장 검사도 연결했습니다.

[실제 수정 전후](before-after.md) · [2027년 여섯 분야 전체 예문](profile-1-year.md) · [월간 전체 예문](profile-1-month.md)

자동 검사는 알려진 문법 오류·동일 문장·원고 연결과 해시를 확인하는 장치입니다. 모든 문장의 자연스러움이나 명리학적 정확성을 인증하는 점수가 아닙니다. 이번 결과는 작성자 검토이며 독립 전문가 검토를 마쳤다고 표시하지 않습니다.
