# 분야별 문장을 읽는 기준

같은 사주 조건을 활용하더라도 분야 이름만 바꾸어 같은 조언을 반복하지 않습니다. 아래는 집필·문맥 검토 기준이며, 계산식이나 길흉·점수 재조정 기준이 아닙니다.

| 분야 | 독자가 알고 싶은 일 | 이번 2027년 예문의 관점 | 다른 분야와 구분할 점 |
|---|---|---|---|
| 총운 | 어떤 선택이 내게 의미 있는가 | 남의 평가와 자신의 보람, 경험 뒤의 만족 | 사업의 계약·납품 조언을 그대로 복사하지 않음 |
| 학업 | 무엇을 이해했고 어디에 써볼까 | 책을 덮고 설명하기, 다른 문제에 적용하기 | 강의 비용·예산 관리가 본문 전체를 대신하지 않음 |
| 재물 | 들어온 돈 중 실제로 쓸 금액은 얼마인가 | 불규칙한 수입과 정기 생활비, 미확정 수입 | 해당 분야에서는 돈·정산·납부의 구체적 설명을 유지 |
| 건강 | 생활에서 편히 쉬고 움직일 방법은 무엇인가 | 식사·잠들기 전 쉼·작게 실천할 습관 | 업무 계획만 설명하지 않음. 질병이나 체력을 사주로 판정하지 않음 |
| 연애 | 관심을 어떻게 주고받고 상대를 알아갈까 | 작은 표현, 상대 취향, 아직 상대가 없는 경우 | 만남의 비용·시간 조정만 반복하지 않음. 연애 상태를 추정하지 않음 |
| 사업 | 상대가 필요로 하는 일과 내 경험을 어떻게 맞출까 | 지원 역할에 맞는 경험, 실제로 쓰일 결과 | 생활 전반의 만족이나 공부 방법을 분야명만 바꾸어 재사용하지 않음 |

건강 원고 90개 전체를 생활 관점으로 다시 썼습니다. 세부 조건 중 ‘돈을 낸 활동 때문에 쉬지 못하는 경우’는 구체적인 건강·생활 상황이므로 비용이라는 단어를 기계적으로 금지하지 않았습니다. 현재 몸이 불편하면 비용보다 쉬는 선택을 우선하는 내용으로 다룹니다.

일·월·연은 실제 조회 범위에 맞게 씁니다. 월간 문단에 연간 행동 주기를 넣거나 시주의 글자를 실제 하루 특정 시각의 몸 상태로 해석하지 않습니다. 다른 시기에 적용되는 본문도 자체 완성 문단으로 읽습니다. 보충 문단의 원고 ID와 실제 적용 시기는 내부 trace에 남겨두며 공개 연결 문장을 여섯 번 붙이지 않습니다.

동일 문장 검사는 복제를 찾는 보조 검사입니다. 서로 다른 단어를 쓰거나 문자열이 겹치지 않는 것만으로 분야별 가치가 확보됐다고 판단하지 않습니다. 원고의 의미 검토에는 전체 여섯 분야를 함께 읽고, 각 분야의 독자 질문에 별도로 답하는지 확인하는 과정이 필요합니다.
