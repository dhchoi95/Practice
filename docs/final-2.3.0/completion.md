## 원고 교정

일·월·연 여섯 분야540개(기존180개 의미 묶음), 일정36개, 상세 원국62개, 상세 기간136개, 기존 주제210개, MBTI96개와 유형 기본 설명16개, 일상 편집31개, 근거25개, 공통 오행5개, 용어9개, 안내17절, 출처 설명5개, 기간 안내3개와 비활성 실험4개를 목록화했습니다. 총1195개는 서로 독립적인 운세 상황1195개나 전문가 검수 수를 뜻하지 않습니다. 도시명·좌표는 별도 참고표로 유지합니다. UI·오류·공유·생성 설명74개 소스 파일도 문자열 목록으로 별도 기록했습니다.

본문·제목·생활 제안·근거의 기존 뜻과 한계를 보존하면서 필요한 표현을 고쳤습니다. 자연스러운 짧은 안내는 유지했습니다. 일간180개는 앞 차수의 교정을 보존하고 월·연360개는 기간별 상황에 맞춰 집필했습니다. 상세 원고는 전문적인 사실과 제한을 남기면서 합니다체·표기를 다듬었으며, 기간 십신의 기본 흐름10개와 추상적인 원국 제목40개는 내용을 직접 드러내도록 고쳤습니다. 추가 생성은 `writing-and-generation.md`를 따릅니다.

대표 전후:

- “가능한 시간과 어려운 조건을 나누어 말하면 서로 선택할 범위가 보여요.” → “이번 달은 서로 일정이 맞지 않아 아쉬움을 느낄 수 있습니다. 만날 시간을 잡기 어렵다는 이유만으로 관심이 없다고 단정하지는 마십시오. 가능한 시간과 어려운 사정을 나누면 다른 방법을 찾기 쉽겠습니다.”
- “표현과 평가 기준이 함께 확인됩니다.” → 면접 안내에서 “오늘은 많은 이야기를 하기보다 질문의 범위에 맞게 답하는 편이 좋겠습니다.”로 상황을 먼저 설명합니다.
- “식신의 자원 주제” 같은 제목 → “제작 비용과 실제 수요를 함께 보기”, 원국의 “편관의 구성 주제” → “식신과 편관만으로 제살격을 정하지 않는 이유”처럼 실제 본문의 내용을 드러냅니다.

현재 해시·전후·구현자 재검토 기록을 남기고 과거 기록은 보존했습니다. 계산·선정 전제·기여값과 전문가 검수 상태는 바꾸지 않았습니다. 자연스러움의 독립 편집 검토와 명리 해석의 독립 전문가 검토는 대기합니다.

## 제품 변경과 남긴 범위

지정한5개·4×2·3×3 메뉴, 다음 해 기본 신년운세와 연도 선택, 현재 해 바로보기, 출생정보→원국표→해설/여섯 분야, 검증한12운성, 별도 A/B 짝궁합 입력과 실제 두 원국 비교를 구현했습니다. 기존 상세 원국 해설은 접어 볼 수 있게 보존했습니다.2050년에서는 상세 세운도 지원 범위 안에서만 표시합니다. 상단의 시간 보정과 접힌 상세 해설이 같은 출생정보를 읽도록 상태를 통일했으며 양방향 설정 변경을 검사했습니다. 혈액형은 진입에서 제거하고 구 URL에 종료 안내를 제공합니다.

다섯 날짜의 사진·문서 조건을 재현한 범위에서 기존 핵심 원국 오류는 발견하지 못해 계산을 유지했습니다. 자정·미상·표준시·평균태양시·진태양시를 구분합니다. 사진의 강약 점수나 원국에 맞추려고 산식을 바꾸지 않았습니다.12신살·공망은 미지원으로 명시했습니다. 상세 기준은 `calculation-and-product.md`에 있습니다.
