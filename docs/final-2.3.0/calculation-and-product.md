# 계산 기준과 이번 제품 변경

사진과 첨부 MD를 참고해 정보의 순서와 메뉴를 변경했습니다. 외부 앱의 디자인·캐릭터·광고는 복제하지 않았습니다. 첫 네 장의 자정 표시와 뒤 사진들의 시간 모름은 서로 다른 입력입니다. 사진만으로 실제 생시·출생지·앱의 보정 설정을 추정하지 않습니다.

## 계산을 유지한 범위

기존 역법·절입·일주·시주·태양시·강약 판단식과 여섯 분야 지수의 숫자는 변경하지 않았습니다. 다섯 날짜의 표준시 원국·한국 음력 왕복, 세 날짜의 자정/미상 분리, 서울 지방평균태양시 두 사례와 진태양시의 차이를 회귀 검사에 추가했습니다. 공식 달력을 이번 세션에 새로 조회했다고 주장하지 않으며 첨부 보고서의 독립 검증 범위와 현재 코드의 재현 검사를 구별합니다. GPT의 즉석 답변은 정답 기준이 아닙니다.

새로 구현한12운성은 일간 기준, 양간 순행·음간 역행입니다. 장생 지지는 갑亥·을午·병寅·정酉·무寅·기酉·경巳·신子·임申·계卯입니다. 토는 화를 따르는 채택표입니다. 임관/临官은 건록, 冠带는 관대, 墓는 묘, 死는 사로 표기합니다. 경금未=관대·申=건록, 계수未=묘·申=사를 검사했습니다. 병·사·묘를 실제 질병·수명의 단계로 읽지 않습니다. 모든 학파의 공통 표라고 주장하지 않습니다.

기존 지장간 본기·중기·여기 표와 십신을 유지합니다. 지지의 음양과 본기 천간의 음양은 별개입니다. 12신살·공망은 채택·검증한 표가 없어 미지원으로 명시했습니다. 사진의 강약 점수50·40·60·20에 맞춰 가중치를 조정하지 않았습니다. 기존 월령·뿌리 판단과 단순 글자 개수도 구별합니다.

## 메뉴와 입력 상태

상단5개는 신년 운세/오늘의 운세/이번달 운세/지정일 운세/올해 운세입니다. 다음4×2, 그다음3×3은 사용자 지정 순서를 따릅니다. 기존 배경·폰트·색상·카드·SVG를 유지했습니다. 상단 분류는 좁은 화면에서 가로 스크롤과 키보드 탐색을 지원합니다.

기존 `/fortune/saju/`·`/result/saju/`는 신년운세로 연결합니다. 한국시간 현재 해의 다음 해가 첫 기본값이며,2050년 지원 상한에서는2050년을 씁니다. 선택 연도는 브라우저 메모리에 유지합니다. 올해 운세는 한국시간 현재 연도로 고정합니다. 같은 연도의 여섯 분야는 같은 엔진·조건을 공유합니다.1월1일부터12월31일을 조회하되 입춘 전후의 간지년과 기간 내 실제 경계를 나누어 계산합니다. 상세 세운은 선택 연도에서 최대5년이며 지원 상한2050년을 넘기지 않습니다.

신년운세와 만세력은 출생정보 요약(양력·한국 음력·윤달·입력 시각)→적용 기준·도시→접히지 않은 시/일/월/년4열 원국→해설 순서입니다. 신년운세에는 연간 여섯 분야가 이어집니다. 기존 강약·격국·용신·희신·대운·세운·성격·일·돈·연애 해설은 상세 펼침 안에 보존합니다. 확정되지 않은 값을 자정이나 서울로 채우지 않습니다.

짝궁합은 A/B 각각의 출생정보·계산 설정을 별도로 유지합니다. 실제 두 원국의 십신과 교차 합충을 비교하며 한 사람 연애사주를 복제하지 않습니다. 관계의 성패 점수·배우자 역할 추정은 추가하지 않았습니다. 이름은 계산에 쓰지 않고 한 사람의 미상 시주도 채우지 않습니다. 이 기능은 전통 관계표를 읽는 비교이며 관계의 적중률을 입증한 결과가 아닙니다.

MBTI·띠·별자리는 직접 선택한 유형의 읽을거리입니다. 한국시간 날짜는 정해진 편집 순환에 쓰고 새로고침마다 임의 변경하지 않습니다. 띠는 한국 음력 설, 별자리는 기존 양력 월일표를 유지합니다. 혈액형은 새 진입 메뉴·추천에서 제거했고 기존 URL은 제공 종료 안내를 표시합니다. 보관된 데이터와 과거 검토 기록은 삭제하지 않습니다.

선택 날짜·연도·A/B는 출생 원국과 다른 상태입니다. 오늘/이달/올해에는 지정일 입력과 일정 선택을 섞지 않습니다. 지정일은 날짜를 고르기 전 결과를 출력하지 않습니다. 일정 선택은 준비 설명만 바꾸고 지수는 바꾸지 않습니다. 모든 입력은 현재 브라우저 메모리에서만 사용하며 새 영구 저장·분석 이벤트·출생정보 URL·외부 LLM을 추가하지 않았습니다.
