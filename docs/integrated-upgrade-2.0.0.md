기준은 2026-10-22의 로컬 커밋 `eee3ef1`이다. 이 기준의 실제 검사는 단위·통합 296개, 기존 정상 210개·공통 설명 5개·근거 25개·draft 4개였다. 1.4.0 한국어 교정과 기존 검토 687개를 보존했다. 이번 지시는 원격 push·공개 배포를 금지하므로 로컬 구현·검증·검토 자료만 만든다.

## 사용자 예시에서 실제로 달라진 값

양력 1995-11-08 15:03, 전통 남성 분류, 2026~2030 비교다. 도시 미상을 수원으로 바꾸지 않았다.

| 항목 | 표준시 | 수원 명시 진태양시 |
|---|---|---|
| 출생 명리 시각 | 15:03 | 약 14:47 |
| 원국 | 을해·정해·계묘·경신 | 을해·정해·계묘·기미 |
| 시지 지장간 | 경·임·무 | 기·정·을 |
| 목 삼합 | 세 지지 없음 | 해·묘·미 후보 1개, 합화 미확정 |
| 강약 후보 | 신강 경향, 채택식 8.3 | 중화·경계, 채택식 3.0 |
| 격국 후보 | 월겁 계열 | 월겁 계열 유지 |
| 억부 후보 | 목·화 | 경계라 유보 |
| 겨울 조후 후보 | 화 | 화 유지 |
| 대운 | 역행 병술→을유→갑신→계미 | 실제 출생·절입 순간이 같아 유지 |

입동과 실제 출생의 차이는 약 8.45694시간이다. 채택한 환산·표준시 달력 가산에서는 **1995-12-20 21:53** 개시, 계미 구간은 **2025-12-20 21:53~2035-12-20 21:53 전까지**다. 초 단위 절입 모델과 달력 가산 방식이 다르면 개시 날짜도 달라질 수 있다. 참고문의 12월 하순이나 신강 판단에 수치를 맞추지 않았다. 성남·안양도 각 도시의 경도로 계산하며 도시 미상은 태양시를 확정하지 않는다.

별도 천문 모델과 절입 72개를 비교한 차이는 기존 허용치 90초 이내였다. 균시차는 6개 연도×365일의 관측 최대 차이 약 0.832분이다. 지장간은 12지지의 본기·구성 글자가 소프트웨어 표와 같다. 마지막 대조에서 巳의 보조 순서는 서비스 丙·戊·庚, 소프트웨어 丙·庚·戊로 달랐다. 순서까지 일치한다고 처리하지 않고 고정 순서·가중치의 정책 차이와 원전 검토 대기를 기록했다. 이 차이는 巳가 있는 원국의 강약 후보에 영향을 줄 수 있다. 소프트웨어 비교와 실제 만세력·원전의 독립 검증은 다르다.

## 장기간·한국어·조립 검토

합성 원국 33개에 10일간·여러 계절·시각 미상·순역 후보를 포함하고 각각 365일, 12개월, 2025~2030 결과를 만들었다. 완성 본문과 원고 ID 조합의 반복을 따로 세었다. 미확정 일간의 제한 안내는 적은 종류로 반복되는 것이 맞고, 365일 모두 다르게 만들지 않는다. 날짜·제목·실제 간지만 다른 결과를 새 본문으로 세지 않았다.

대표 전체 결과를 읽고 ID 순서에 치우친 기본 주제 선정, 기간끼리의 충을 원국 충으로 설명할 수 있던 조건, 잘못된 조사, 기간·5년 표 사이 동일 문단의 재출력을 고쳤다. 동일 설명은 처음 표시한 위치만 본문·제안을 싣고 뒤에는 해당 연도·구간 참조를 남긴다. 해마다 바뀐 실제 간지와 대운·추가 관계는 계속 표시한다. 예시의 기본 주제+5년 해석은 중복 제거 후 약 5,700자 수준이며 계산표·근거·비교는 별도다.

한국어는 기존에 읽은 korean-skills humanizer 1.6.0 → grammar-checker 1.0.1 → style-guide 1.1.0을 기준으로 직접 집필하고 전체 출력에서 다시 확인했다. 단어 빈도·AI 탐지·변경률을 합격 기준으로 쓰지 않았다. 새 원고의 `authoringIntent`는 전제와 역할의 집필 기록이며 개별 편집 승인 점수가 아니다. 실제 수정 전후와 구체적인 이유는 `integrated-korean-editing.json`에 있다. 새로 쓴 원고에 가상의 수정 전 문장을 만들지 않았다.

## 검증과 전달

최종 검사는 단위·통합 330개, 전체 Chromium 69개, 기존 PDF 13개와 상세 PDF 3개를 통과했다. 상세 표기·인쇄 보완 뒤에는 영향을 받는 상세 E2E 5개와 상세 PDF 3개를 다시 실행해 통과했다. MBTI 주제 선택창은 실제 모바일 화면 확인 후 높이 44px 이상으로 보완하고 해당 전환 검사를 다시 통과했다. 정적 산출물은 213개, draft 유출은 0개다.

최종 원본 로그와 상태는 검토 묶음의 `reports/integrated-2.0.0/` 및 `checks.json`을 따른다. 개발 중 실패 로그도 남겼다. 처음 발생한 타입·미확정 초기값 오류는 수정했다. E2E의 두 실패는 로딩 알림/공유 알림의 구분과 생활 제안/상세 진입 패널의 구분 문제였으며 기존 검사를 삭제하지 않고 원인을 수정했다. tsx IPC 우회는 필요하지 않았다. 새 npm 설치·원격 CI·운영 URL·실제 휴대전화·인스타그램 인앱·새 Lighthouse·OS 인쇄 대화상자·물리 프린터는 검증했다고 주장하지 않는다.

검토 ZIP은 START_HERE부터 읽는다. 원래 통합 요구, 현재/이전 소스, 정책, 원고·출처·검토 이력, 표준시/태양시 결과와 차이, 다른 원국과 기간 전후, 장기간 분석, 실제 화면·PDF·정적 빌드를 포함한다. Node 24.19.0에서 `npm ci`, `npm run verify`, `npm run build`, `npm run test:e2e`로 재현할 수 있다. 현재 환경은 기존 의존성을 재사용했으며 실행 중 LLM·DB·결제·로그인을 추가하지 않았다.

남은 검토는 고전 원문·도시 좌표의 출처 대조, 독립 한국어 편집·명리 규칙 검토, 실제 휴대전화와 인앱이다. 사령 일수·합화 확정·특수격·종격·세밀한 습조는 구현 범위를 제한했다. 사용자 지시에 따라 이번에는 원격 push·공개 배포·공개 테스트 URL 발급을 하지 않았다.

자정이 지나면 기본 조회일은 한국 날짜의 오늘로 갱신한다. 사용자가 직접 고른 날짜와 연도는 유지하며, 오늘 버튼을 누르면 기본 조회로 돌아간다. 이 동작을 포함한 최종 전체 브라우저 검사 69개를 통과했다.
