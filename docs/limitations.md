# 지원 제한과 운영 전 확인

## 의도적인 지원 범위

- 한국 출생, 변환한 양력 1962-01-01~한국시간 오늘. 달력 상한 2050-12-31, 기간 운세 2050년까지.
- 해외 출생·1962년 이전 표준시 변경·진태양시·지역 경도 보정은 제공하지 않습니다.
- 정확 시·분 또는 시간 미상만 받습니다. IANA gap/fold 시각은 임의 선택하지 않으며 시간 미상으로 제한 풀이가 가능합니다.
- 시간 미상은 시주를 만들지 않습니다. 절입일의 연·월주, DST 환산에 따라 달라지는 일주도 미확정일 수 있습니다.
- 지장간·합충·신강신약·격국·용신·대운·궁합·작명·택일·이미지 저장은 구현하지 않았으며 메뉴에 작동하는 것처럼 표시하지 않습니다.
- 기본 저장은 메모리뿐입니다. 새로고침·새 문서에서는 입력을 다시 해야 합니다. 기기 영구 저장 기능이 있는 것처럼 표시하지 않습니다.

## 검증 범위의 경계

독립 ICU 한국 달력과 천문 모델을 비교했지만 한국천문연구원 직접 API 조회·공인 사주 검증은 아닙니다. 절기 비교의 90초 허용치는 천문 모델 간 비교 범위이고 실제 초 단위 오차 보증이 아닙니다. 절입 가까이에서는 다른 자료·기준의 결과와 다를 수 있습니다.

원고 180개는 독립 작성한 자동 검사 상태이며 사람·명리 전문가 검토를 마쳤다는 뜻이 아닙니다. 같은 상징을 실제 성격·수입·질병·혼인 여부의 진단이나 미래 예언으로 사용하지 않습니다. 마음돌봄은 일상 제안이며 치료가 아닙니다.

실제 iOS Safari·Android Chrome 기기와 인스타그램 인앱 브라우저는 이 환경에서 검증하지 않았습니다. Chromium의 화면 폭·터치 에뮬레이션, 공유 API 성공/취소/미지원 모의 검사는 실기기 검증과 구분합니다. Lighthouse는 로컬 실험 결과이며 현장 성능을 보장하지 않습니다.

## 운영자가 공개 전에 할 일

- 실제 서비스명과 상표 사용 가능 여부, 도메인·호스팅·운영 연락처 결정.
- `NEXT_PUBLIC_SITE_URL`, 실제 연락처·호스팅 로그 정책에 맞춘 개인정보 안내 갱신.
- 독립적인 명리 원고 검토와 한국어 의미·모순 검토. 상태를 실제 검토 수준에 맞게 변경.
- 인스타그램 iOS/Android 실기기에서 입력·키보드·회전·공유·복사·인쇄 안내 확인.
- 정적 호스팅의 내부 경로/404/HTTPS/압축/캐시 설정 후 별도 공개 검증.

계산·입력·개인정보·결과 연결의 미구현을 운영자 작업으로 남기지 않습니다. 외부 계정 가입·결제·공개 배포는 이번 실행 범위 밖입니다.
