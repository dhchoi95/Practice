- 입력·결과·A/B 궁합의 도시와 태양시 선택을 제거했습니다. 새 일반 입력은 한국 표준시를 사용합니다. 남은 메모리의 보정 상태는 표준시로 원국·본문·대운을 함께 재계산하고 한 번 안내합니다.
- 항상 보이는 원국표, 십신·지장간·12운성, 이름·출생정보, 여섯 분야·점수·그래프, 지정일의 일정 참고, 연도 선택, 원국 상세와 대운은 유지했습니다. 선택 성별이 없거나 출생 시각을 모르면 대운 방향/시작을 임의로 채우지 않습니다.
- 만세력의 오행 분포와 개인별 원국 해설을 유지하고, 격국·용신은 실제 계산된 조건을 짧게 설명합니다. 중복된 계산 표·시각 비교·5년 세운의 내부 구간 나열은 출력하지 않습니다.
- 짝궁합은 동일한 합·충 설명을 종류별 한 번으로 묶고 해당 위치를 남겼습니다. 두 사람의 계산 결과나 관계 판정 조건은 바꾸지 않았습니다.
- 홈 디자인·색상·글꼴·카드 스타일·5개/8개/9개 메뉴 순서와 연결을 유지했습니다. 안내 페이지의 과거 시각 선택 설명만 실제 동작에 맞췄습니다.

자세한 파일·원고 연결은 [공개 출력 경로 목록](output-inventory.md)을 참고하십시오.

## 실제 교정 수와 기록

실제 제목/본문을 고친 원고는 **94개: 원국 62개 + 분야 32개**입니다. 단순 문자열 교체 횟수나 출력 문단 수가 아닙니다. 원국 62개에는 현재 일반 결과에서 사용하지 않는 `god-caution` 역할 10개도 포함됩니다. 이 10개를 새 공개 해설로 억지로 노출하지 않았습니다.

분야 540개 중 나머지 508개, 기존 주제별 사주 210개, MBTI 원고 112개 등은 기존 본문을 보존했습니다. 전체 원고·설명 목록 1,195개를 다시 산출하고 출력 경로와 조립 예문을 점검했지만, **1,195개를 모두 새로 교정했다는 뜻은 아닙니다.** 기존 기간 원고 136개는 내부 기록·검증용으로 남아 있으며 이번 일반 화면에서 출력하지 않습니다.

원국 공개 문장은 `src/content/advanced/natal-copy.json`, 분야 문장은 `src/content/foundation/sectors.json`에 저장했습니다. 원국 조건 정의 파일에서 공개 문장과 claim.text를 함께 적용합니다. 버전은 2.4.0이며, 바꾸지 않은 기존 사주 원고의 버전은 2.3.0으로 유지했습니다. 과거 검토 이력·스냅샷을 수정하지 않고 현재 해시의 작성자 검토를 추가했습니다. 독립 승인 상태로 올리지 않았습니다.

이번 변경 파일은 추가·삭제·생성 검토 자료를 포함해 57개입니다. 전체 파일명은 `content-review/copy-cleanup/changed-files.json`에 있습니다.

전체 전후 원문·해시·조건 보존 결과는 `content-review/copy-cleanup/`에 있습니다. [실제 수정 전후 8건](before-after.md)에서 제목·본문·수정 이유를 확인할 수 있습니다. 이후 원고는 [집필·교정 규칙](writing-rules.md)에 따라 작은 조건 묶음으로 작성하고 조립 결과까지 읽도록 정리했습니다.
