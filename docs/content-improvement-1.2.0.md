# 콘텐츠 1.2.0 수정 및 재검토 자료

2026-10-20. 기준은 로컬 커밋 `ee075ce`의 콘텐츠 1.1.0이다. 독립 검토의 CR-01·CR-02를 재현한 뒤 수정하고 근거·평가·검토 절차를 개선했다. 외부 배포·원격 push·외부 메시지·유료 가입·모델 학습/API 호출은 실행하지 않았다.

## 범위와 남은 판단

같은 신금+식상2에서 재성1이면 전달·실제 시간/비용, 인성1이면 배운 것을 적용하는 질문으로 나눴다. 이는 내부 편집 설계이며 식상생재·강약·학력·매출을 증명하지 않는다. 일반 사이트가 자동으로 이 초안을 쓰지 않도록 코드 의존성과 실제 번들을 확인했다.

전체 결과 메모에는 종합 풀이에서 완료 기준·확인·약속이 겹치는 점을 남겼다. 단어·문자열 중복 검사가 통과했다고 의미 반복이 없다고 승인하지 않는다. 문맥·행동 충돌·해석의 적절성은 `content-review/assembled-notes.md`와 semantic-cases의 후보를 독립 검토자가 확인해야 한다. 외부 원전과 전문 명리 검토를 확보했다고 주장하지 않는다. 외부 출처 3개는 이번 작업에서 실제 페이지를 새로 확인하지 못했으므로 확인일·저자·검토자는 비워 두고 대기 상태로 두었다.

계산 소스와 정책은 변경하지 않았다. 기간 이력은 메모리/로컬 진단에만 있으며 출생정보·개인 결과·식별 해시를 수집하는 서버나 브라우저 영속 저장을 추가하지 않았다. 모바일 320/390px, 별자리 195px, 확대·회전·키보드·axe·시간 미상·윤달·DST·수정/삭제/새로고침·요청/URL/콘솔/저장소/쿠키 회귀를 로컬에서 확인했다. 실제 운영 주소·인스타그램 인앱 실기기·새 Lighthouse 측정·독립 재검토는 **미실행**이다.
