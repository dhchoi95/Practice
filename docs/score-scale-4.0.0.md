# 분야별 참고 지수 4.0.0

사주에서 계산한 일간·기간 천간과 지지, 십성, 원국과의 합·충 후보, 강약 후보를 기존 분야별 원고의 선정 조건에 사용한다. 원고에 연결된 기여값은 이 서비스가 정한 상징적 해석 정책이며 명리학의 공인 점수 공식이나 실제 사건의 확률이 아니다. 상세 조건과 사용한 원고 ID, 각 기여값은 `SectorJudgment.selectionTrace`와 `contributions`에 남는다. 총운은 개별 총운 원고의 기여가 아니라 다섯 분야의 같은 비중 평균이며 `scoreInputs`에 그 값을 기록한다.

기존 3.0은 선택된 원고의 기여 중 같은 근거군의 첫 값만 반영해 다른 선택 원고의 반대 기여를 버렸다. 4.0은 동일 근거군에서 양수 중 가장 큰 값과 음수 중 가장 작은 값을 각각 최대 한 번 사용한다. 예를 들어 같은 근거군에서 +5와 -5가 함께 선택되면 0으로 균형을 맞추며, +5가 여러 개라고 중복 가산하지 않는다. 나머지 근거군 합은 ±25로 제한하고 50을 더해 원점수로 삼는다. 부호와 크기 자체는 기존 분야별 원고에 연결된 편집적 기여값이며 독립적인 고전 명리 가중치로 검증되지 않았다.

표시 점수는 원점수와 별도로 관리한다. 50 이하에서는 `50 + 2 × (원점수 − 50)`, 50 초과에서는 `50 + 3 × min(원점수 − 50, 10) + 2 × max(원점수 − 60, 0)`을 적용하고 0~100으로 제한한 뒤 5점 단위로 반올림한다. 예: 원점수 40→30, 45→40, 50→50, 55→65, 60→80, 65→90. 단조 변환이지만 5점 차이가 15점으로 확대되기도 하므로 객관적으로 더 정확해졌다는 의미는 아니다. 월·연간은 구간별 표시점수를 실제 기간으로 가중 평균하므로 전체 원점수를 한 번 변환한 값과 반올림상 다를 수 있다.

동일 합성 인물 1,000명과 7개 날짜로 3.0과 4.0을 대조한 상세 통계는 `docs/score-content-review/v4-distribution.json`이다. 40~60점 구간 비율은 학업 96.0→62.7%, 재물 89.7→54.6%, 건강 95.8→82.0%, 연애 96.6→74.7%, 사업 87.4→56.3%다. 총운은 다섯 분야 평균이므로 94.4→93.4%로 여전히 집중된다. 여섯 점수의 인물별 평균 범위는 16.09→20.11점이다. 표본은 인구 대표 표본이 아니다. 40~60과 60~80 구간은 60을 양쪽에 포함한다.

요청한 50~60점 구간만 별도로 보면 총운 80.8→71.9%, 학업 79.2→44.1%, 재물 74.6→37.9%, 건강 58.7→44.4%, 연애 81.9→53.8%, 사업 81.6→45.8%다. 총운은 이 기준에서도 집중이 남아 완료 조건을 충족했다고 볼 수 없다.

원고의 후보 조건과 기여량은 기존 데이터를 사용한다. 서로 다른 해석의 가중치를 객관적으로 입증한 것은 아니며, 3.0의 연구 자료에서 발견한 중복 기여의 처리 방식을 바꾼 것이다. 건강 지수는 질병·진단을 나타내지 않는다. 시각·일간 미확정은 기존대로 보류하고, 이미 저장된 영구 결과는 없으며 공유는 개인 점수 없이 메뉴 링크만 전달한다. 후속 작업은 각 분야의 근거·원고·점수 방향에 대한 독립 명리 및 편집 검토와 총운 집중 문제 해결이다.
