## 편집 과정과 증거

대표16개로 먼저 문체 기준과 전후를 작성한 뒤 전체를 검토했다. 대표는13메뉴와 오행·관계 보완·시간 미상을 포함한 서로 다른16개 원고다. 초기 단계는 representative-stage.json, 최종24쌍은 editorial-before-after.md/JSON, 모든 변경/유지는 editorial-audit.json에 있다. 원고 수와 메뉴 수를 중복 합산하지 않는다.

원래6개 합성 프로필의 전후 전체를 읽었다. 기본·보완을 합친 반복, 행동 순서, 근거, 시간, 미확정 범위를 content-review/assembled-notes.md에 남겼다. 수정 전 전체는 이전 실행의 보존 산출물이고, 수정 후는 이번에 실제 생성했다. baseline의 단위·통합283개는 이번에 직접 실행했다. 출생 계산 feature와 계산 버전은6개 모두 일치했다. 자동 검사 결과를 독립 편집 승인으로 표현하지 않는다.

바뀐 기대 문구는 관계 보완 제목2개와 그 부재 검사, 연간 근거의 자연스러운 ‘편재를/정관을 이 구간의 생활 이야기’다. 같은 관계가 선택되는지, 올바른 조사인지 확인하는 검사를 유지했다. PDF에도 같은 어휘를 반영하고, 교정된 본문·기간 날짜의 새 포함 검사를 더했다. 어색한 옛 문구를 강제로 유지하거나 검사를 삭제하지 않았다.

실행 로그와 hashes는 reports/content-improvement-1.3.0 및 검토 패키지에 있다. 이번 환경에서는 npm 명령을 그대로 실행했다. tsx IPC 우회는 사용하지 않았다. 개발 중 발견한 조사/TypeScript 문제는 고친 뒤 해당 검사와 최종 검사를 다시 실행했다. 원격 Actions 실행이나 새 환경 설치를 검증했다고 주장하지 않는다.

## 한계와 전달

이번 교정은 이 개발 세션에서 수행했다. 실제 한국어 편집자·명리 전문가가 승인한 원고가 아니다. 외부3개 출처는 이번에도 새 확인 완료로 바꾸지 않았다. 의미 사례10개와 독립 검토 대기139개는 pending이다. 현재 화면·원고는 정적 소스와 메모리 계산을 사용하며 LLM·서버DB·방문자 피드백 수집을 추가하지 않았다.

실제 스마트폰·인스타그램 인앱·운영URL·원격CI·새Lighthouse·OS인쇄대화상자/물리프린터·전문가 확인은 미실행이다. 이번 수정은 운영 홈페이지에 자동 반영하지 않았다. 로컬 정적 파일과 새 독립 검토 묶음만 만들었다.

다음 검토자는 새 패키지의 START_HERE와 review-request부터 읽고, 원고 전문·24쌍·6개 전후 전체·조건·근거·검토 이력·실제화면·PDF를 직접 대조한다. 세부 구조는 editorial-standard-1.3.0.md와 review-history-1.3.0.md를 따른다.
