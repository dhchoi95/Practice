# 하루사주 구현 계획

첨부 실행 프롬프트 전체의 P0를 대상으로 한다. 초기 저장소는 커밋·파일이 없는 상태였다.

1. 조사: Next.js 공식 정적 export 문서와 두 달력 패키지 원저자 문서·소스·라이선스 확인.
2. 계산: 한국 음력 어댑터, IANA 한국 시계→표준시 정규화, 절입 기반 연·월주, 자정 일주, 기본 관계 분석. 경계 fixture부터 검증.
3. 화면: 따뜻한 흰색·적갈색·먹색, 직접 만든 SVG, 3×3 운세 타일. 320px부터 반응형.
4. 콘텐츠: 최소 180개 독립 원고, 선언형 조건·스키마·결정적 선택·의미 충돌 처리, 운영 명령.
5. 전체 흐름: 13개 메뉴, 브라우저 메모리 상태, 기간·가벼운 운세, 공유·인쇄·안내·SEO.
6. 검증: lint/typecheck/단위·통합 테스트/production export/실제 Chromium E2E/화면 캡처/네트워크 검사.

## 완료 기준

- 생년월일과 계산 feature가 실제 결과에 반영된다. 경계·시간 미상의 미확정 값은 명시적으로 제한한다.
- 기본 1962-01-01~한국시간 오늘, 한국 출생. API·가입·방문자 DB·분석 도구 없음.
- 원국 계산, 관계 분석, 콘텐츠 저장소, UI를 분리한다.
- 공개된 모든 메뉴는 동작하고 개인정보는 URL·요청·영구 저장에 들어가지 않는다.
- 독립적 비교와 동일 엔진 회귀 검사를 구분한다. 미실행 검증을 성공으로 표시하지 않는다.
- 최종 결과와 근거는 acceptance-checklist 및 verification-report에서 추적한다.

P1 이미지 저장·대운·해외 출생·진태양시는 제외한다. 실기기 인앱 브라우저와 독립 명리 원고 검토는 운영 전 확인한다.
