# AI 사주 개인정보·약관·투명성 초안

이 문서는 운영자의 처리 구조 확정과 법률 검토를 위한 초안이다. 법 준수 완료 문서가 아니다. 현재 실제 가입/유료 AI는 비활성이다. 준비 중 화면·코드 배포 방침과 실제 처리 개방은 구분하며 배포 상태는 검증 보고서를 따른다.

## 처리 매핑

| 처리 | 최소 항목 | 목적·후보 근거 | 위치·상대 | 초안 보유·삭제 |
|---|---|---|---|---|
| 소셜 인증 시작/콜백 | 일회 state 바인딩 해시, 암호화한 verifier·nonce, 제공자 ID | 가입 요청 전 인증 절차. 적법 근거는 운영자 확정 | 서버와 선택 IdP | 10분 유효, 정리 작업으로 제거 |
| 가입 대기 | 제공자·고유 ID의 키 있는 요약 | 가입 절차 이행, 운영자 근거 확정 | Cloudflare SQLite | 10분 유효, 미완료 계정은 만들지 않음 |
| 회원 계정 | 내부 ID, 제공자·식별 요약, 가입 시각 | 회원 서비스 이행 후보 | Cloudflare; 실제 저장 위치는 미확정 | 탈퇴 시 제거 |
| 로그인 | 세션 토큰의 해시, 만료·최근 인증 | 인증·계정 보호 | 서버; 브라우저 HttpOnly 쿠키 | 최대 12시간, 로그아웃·탈퇴 시 폐기 |
| 약관·AI 동의 | 목적·문서 버전·시각 | 목적별 근거 증빙 | 서버 | 계정 삭제 시 제거. 별도 보존 필요 여부 운영자 검토 |
| AI 요청 | 출생정보·질문·최근 대화 일부 | 회원이 진단/질문 버튼을 누른 요청 처리. AI 동의는 별도 | 서버 재계산; AI 업체에는 질문·제한 문맥·계산 사실 | 비저장은 요청 중 메모리와 브라우저에만 사용 |
| AI 업체 전송 | 정형 출생 원자료/계정 식별자 제외한 사주 사실·자유 질문·문맥 | 국외 이전·위탁/제3자 제공 등 실제 구조에 따른 근거 확정 | 업체·처리 국가·재위탁·보관정책 미확정 | 업체 계약·설정 확인 전에는 전송 차단 |
| 선택 저장 | 출생 프로필 또는 대화 | 독립적인 저장 선택, 운영자 근거 확정 | 암호화한 Cloudflare SQLite | 초안 90일, 목록·개별·전체 삭제 및 탈퇴 |
| 한도/남용 방지 | 내용의 HMAC·일자·단계·상태, 단기 요청 수 | 서비스 비용·남용 방지의 필요성/비례성 검토 | 서버 | 연결 가능한 식별 요약 7일, 원문 없음 |
| 비용 정산 | 원문 없는 token 수·비용·실패/추정 상태 | 운영·정산 근거 운영자 확정 | 서버 | 초안 30일, 7일 뒤 사용자 연결 제거 |
| 외부 연결 해제 접수 | 제공자 식별 HMAC·대상 계정·처리 상태·철회 시각 | 제공자 통지에 따른 인증 철회·삭제 | 서버 outbox | 완료/철회 요약 7일; 원문 ID·어드민 키 미저장 |
| 서비스 탈퇴/연결 해제 | 처리 확인 상태와 제공자명 | 권리 행사·연동 해제 확인 | 서버 및 재인증한 제공자 | 초안 최소 상태 7일, 불필요한 OAuth 토큰은 보관하지 않음 |

이메일·실명·휴대전화·프로필 사진·소셜 생일·주소·기기 지문을 필수 수집하지 않는다. IP 해시를 이용한 별도 추적도 구현하지 않았다. 일반 호스팅 접속 로그는 애플리케이션 원문 미저장과 별개이다. Worker 관측 로그의 본문 자동 수집은 껐다. 자유 질문에 사용자가 이름·주소를 섞을 가능성이 있어 입력 전 안내와 대표 패턴 차단을 두었지만 완전한 익명화 도구라고 주장하지 않는다.

## 화면의 구분

- 서비스 약관과 성인 대상 확인은 회원 절차이다. 개인정보 처리방침 전체를 동의 하나로 묶지 않는다.
- AI 전송은 가입 후 별도 확인이다. 업체·국가·보관 조건·문의처를 전송 전에 표시한다. 정형 정보와 질문의 실제 전송 범위를 안내한다.
- 출생정보 저장과 대화 저장은 각각 기본 꺼짐이다. 저장하지 않아도 진단을 이용할 수 있다.
- ‘AI 사주’ 제목과 ‘AI가 생성한 사주 해석’을 표시한다. 실제 미래를 보장하지 않는다. 모의 환경은 ‘로컬 모의 답변’으로 구분한다.
- 개인정보 권리 행사는 실제 운영 주체·문의처를 입력한 뒤 제공한다. 문의처 미입력 상태에서 공개 가입을 열지 않는다.

## 출시 전에 확정할 것

1. 운영 주체·문의처, 서비스 국가, 대상 연령과 미성년자 처리. 현재 만 19세 이상 초안·자기 확인만 구현했으며 법적 연령 확인을 완료했다고 볼 수 없다. 추가 신분증/주민등록번호를 수집하지 않는다.
2. 계정/전송/저장 목적별 적법한 처리 근거. 필수 동의와 선택 동의를 구분한다.
3. AI 업체와 Cloudflare의 실제 처리 위치·이전 상대·위탁/재위탁·보관·학습 사용·백업 삭제. 무조건 국외 이전 동의 하나로 충족됐다고 보지 않는다.
4. 외부 제공자에서 먼저 계정을 연결 해제했을 때의 통지·서비스 자료 처리 정책. 카카오 통지는 지시문에 제시된 계약으로 구현했지만 공식 최신 문서·실제 전달 검증 전에는 등록/공개 활성화하지 않는다. 구글·네이버에 카카오 계약을 복제하지 않는다.
5. 침해 의심 시 AI 중단·세션 폐기·키 교체·영향 확인·필요한 통지/신고 절차와 담당자.

## 공식 참고와 현재 확인 범위

2026-10-28에 아래 공식 문서의 재확인을 시도했지만 실행 환경의 네트워크 프록시가 403으로 차단했다. 링크를 읽었다거나 최신 법률 검토가 끝났다고 표시하지 않는다. 설치한 Arctic/jose의 실제 코드·API 형식은 확인했고, 그 사실이 제공자 정책이나 법적 의무 확인을 대신하지는 않는다.
