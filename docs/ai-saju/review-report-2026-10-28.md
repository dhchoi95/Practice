# AI 사주 구현·검증 기록

검증일: 2026-10-28. 출발점: work 브랜치의 4bae012. 이번 변경은 **외부 설정 직전의 로컬 준비본**이다. 원격 push, 공개 배포, 소셜 개발자 앱 생성, 결제·키 등록, 원격 DB 생성은 실행하지 않았다.

## 변경한 동작

상단 메뉴는 AI 사주를 맨 앞에 추가한 6개다. 기존 4×2/3×3 메뉴와 비회원 기본 운세, 원국 계산 엔진, 기존 교정 원고·선정 조건은 유지했다. AI 전용 `/ai-saju/`와 서버 `/api/*`, `/auth/*`만 회원 구조를 사용한다. 기본 운세에 관한 개인정보 설명과 AI 서버 처리 설명을 구분했다.

카카오·Google·네이버 어댑터와 실제 Worker/SQLite 저장소를 구현했다. 회원 권한은 서버 세션으로 확인하고, 한국시간 하루 진단 1회와 후속 2회, 동일 출생정보 묶음, 동시 예약·중복 키·실패/timeout 비용 정산·일/월 총 예산을 SQL 트랜잭션으로 제어한다. 비용이 생긴 실패는 이용 횟수 복구와 별도로 정산한다. 공개 관리자 HTTP 경로는 없다.

소셜 고유 식별자는 제공자별 HMAC으로 분리하고 이메일로 합치지 않는다. 세션/CSRF/state·Google PKCE/nonce/JWT 서명 검증, 서버 재인증을 거친 탈퇴·연결 해제, 서비스 우선 삭제, 소유자별 암호화 자료 접근/삭제를 구현했다. 장기 저장은 출생정보·대화 각각 기본 꺼짐이다. 비저장 답변은 새로고침 뒤 자동 복원/재생성하지 않는다. 선택 저장은 AES-GCM과 사용자/종류/항목별 AAD를 사용하고 삭제 후 진행 중 요청이 다시 저장하는 것을 막는다.

AI에는 서버 계산에서 고른 사주 사실, 질문, 길이를 제한한 최근 문맥만 전송한다. 정형 출생 원자료·소셜 ID·계정 ID·이메일은 모델 payload에 넣지 않는다. 자유 질문의 모든 개인정보를 완벽하게 탐지한다고 주장하지 않는다. schema·factId/quote·연도·간지·미확정 시주·위험한 단정 등 자동 검사는 의미의 정확성을 보장하는 독립 심사를 대신하지 않는다.

## 실제 연결 전에 남은 일

- **실제 카카오/Google/네이버 로그인 및 AI API는 아직 실행하지 않았다.** 실제 OAuth 승인·취소·철회, 모델 JSON schema 지원, 토큰 수/한국어 품질/비용, 인앱 전환은 스테이징에서 검증해야 한다.
- **제공자가 먼저 연결을 해제하는 외부 통지 endpoint는 미구현·미등록**이다. 임의 인증을 꾸며 넣지 않았다. 공식 callback 계약을 확인한 뒤 제공자별 인증·중복 처리 방지를 구현/시험하고 등록해야 한다. 재인증을 통한 서비스 내 탈퇴·unlink 경로와 장애 시 서비스 우선 삭제는 구현했다.
- 공식 OAuth·법률·가격 문서는 프록시 403으로 최신 페이지를 읽지 못했다. 설치한 Arctic/jose 코드·API를 확인한 것과 공식 정책·법률 검토 완료를 구분한다. 출시 플래그는 이를 대신하지 않는다.
- 운영 주체/문의처, 최종 도메인/도메인 소유 확인, AI 업체·처리 국가·보관/학습 정책·법적 근거, 연령·보유/백업 삭제 정책, 실제 가격·일/월 상한은 미확정이다. 약관·개인정보 문서는 초안이다.
- Cloudflare 원격 SQLite/비용/처리 위치/복원·migration rollback, 비밀 관리와 실제 운영 통제 RPC의 접근 권한은 확인하지 않았다. 단일 authority의 실제 부하 시험도 남았다.
- 삭제 후 재가입으로 같은 제공자의 일일 한도를 초기화하지 못하게 했지만 여러 제공자/여러 계정의 동일 인물을 추적하지 않는다. 비용 상한과 전역 동시 요청 제한이 마지막 방어다.
- AI 의미 판단을 전부 정규식으로 보장할 수 없다. 실제 한국어 20건 이상을 진단/후속 단계별로 읽고 token P50/P95와 실패 비용을 기록해야 한다. `ai:cost`의 예시 숫자는 공식 현행 가격/실측/승인 예산이 아니다.

운영 가입·AI 호출은 기본 차단이다. 실제 운영 정보·키·검토·가격·예산 조건을 채워야 열리며, 유료 호출이 불가능할 때 모의 답변을 운영 상담처럼 대신 출력하지 않는다. [USER_ACTION_REQUIRED.md](../../USER_ACTION_REQUIRED.md)에 다음 작업을 모았다.
