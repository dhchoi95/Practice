# 분야별 참고 지수 3.0.0

이 버전은 **기존 분야별 판단의 원점수를 바꾸지 않고 표시 눈금을 변경**한다. 50은 서비스의 산술 기준점이며 객관적인 명리 평균이나 실제 사건의 확률이 아니다. 독립 명리 검토를 완료했다는 뜻도 아니다.

분야별로 일간과 대상 기간의 천간·지지 십성, 원국 월주·일주와의 충·합, 원국 십성, 강약 후보 등 계산 가능한 사실을 원고 조건에 적용한다. 실제 사용하는 조건은 선택된 원고와 미선택 사유의 `selectionTrace`에 남는다. 중심 원고 1개와 호환되는 보완 원고 최대 2개를 선택하며, 같은 기여 근거군은 중심 원고부터 한 번만 반영한다. 각 기여는 -10~10, 합계는 -25~25로 제한한다. 원점수는 50과 이 합의 합이다. 원고와 점수는 같은 판단에서 나오지만, 기존 원고 우선순위가 모든 명리 학파의 판정법을 대표하는 것은 아니다.

표시값은 `50 + 2 × (원점수 − 50)`을 0~100으로 제한해 5점 단위로 반올림한다. 단조 변환이므로 구간별 원점수 순서는 뒤집히지 않지만 같은 5점에 합쳐질 수 있다. 원점수 50·55·60은 표시 50·60·70이다. 55→70, 60→80 예시는 중앙 부근 5점 차이를 20점까지 확대해 과장될 수 있어 채택하지 않았다. 구간별 표시 기준은 90 이상 활용, 60~85 활용과 조율, 30~55 준비와 조율, 25 이하는 범위 축소다.

일운·월운·세운은 해당 기간의 실제 간지와 원국 관계를 사용한다. 월·연 원점수는 실제 기간 구간 길이로 가중 평균한다. 표시점수는 구간별 표시점수를 기간 길이로 가중 평균하고 반올림한다. 총운은 다섯 분야의 점수를 각각 같은 방식으로 집계한 다음, 표시된 다섯 점수를 동일 가중 평균하여 반올림한다. 총운 원점수도 다섯 원점수 평균이다. 따라서 총운 및 여러 구간이 있는 기간의 표시점수는 반올림 순서 때문에 원점수 평균을 바로 변환한 값과 조금 다를 수 있다. 원점수·기여 및 기록 ID·기간 사실과 `scoreVersion`은 내부 결과에 남으며 화면은 단일 표시점수를 공유한다. 일간이 미확정이면 원점수와 표시점수는 모두 보류한다.

## 추가 가산을 보류한 이유

기존 조건은 기간 십성과 원국 관계를 이미 중심·보충 원고에 사용한다. 충이나 합을 분야와 문맥에 관계없이 다시 가산하면 같은 근거를 중복 사용하거나 원고의 조율 설명과 반대 방향이 될 수 있다. 세부 보충의 기여를 중심 기여로 자동 대체하는 방법도 같은 이유로 채택하지 않았다. 예비 가상 입력 120건(2026-10-23, 시간 미상 포함)의 계산에서 유효한 일운 구간·분야 595건 중 선택된 중심과 보충이 같은 기여군인 경우는 116건, 그 기여값이 다른 경우는 84건, 부호가 서로 반대인 경우는 22건이었다. 예를 들어 사업의 `express-standard` 중심 +5와 `detail-02` 보충 -5가 같은 근거군으로 선택된 경우가 있었다. 이 수치는 해당 표본의 기계적 비교이며 해석의 정확성이나 대표성을 입증하지 않는다.

추가 원점수 개선에는 분야별 관계의 의미·우선순위와 서로 다른 기여가 공존할 때의 처리에 관한 편집 및 독립 명리 검토가 필요하다. 그때 근거와 적용 문단을 함께 수정하고 점수·문단 충돌과 일·월·연 분포를 다시 측정해야 한다. 현재 변경을 새로운 명리 기반 가중치의 검증이나 원점수 개선으로 표현하지 않는다.
