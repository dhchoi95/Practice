# 2.2.0 차수 계획

기준 커밋 631da84458b62857a7002914de32e4fa4151e557. 작업 전 변경 없음. 첨부 검토의 비교 623건과 직접 실행한 앱 검사는 구분한다. 기준 엔진으로 고정 12명과 추가 12명을 먼저 재생성하고 원문·선택·완성 본문·해시를 저장한다.

- 고정 집단의 입력/옵션·365일·12개월·2026~2030년을 유지한다. 추가 집단은 별도이며 10일간과 입춘·DST 미확정 사례를 포함한다.
- 정·편 십신, 월지/일지/시주, 노출·뿌리, 대운/기간의 실제 관계를 필요한 질문에만 사용한다. 역법·시간·대운 계산 자체는 바꾸지 않는다.
- 여섯 분야의 독자적인 우선순위를 기록하고 72개 세부 해석 질문을 출발 목표로 집필한다. 기간 변형은 독립 의미로 세지 않는다.
- 공통 계획 문단은 짧은 도움말로 분리하고 기존/새 중심 원고의 기간별 해석을 상황에 맞게 쓴다.
- 의미 축·상충군·중복군과 정확한 문장 중복을 실제 선택에서 제어한다. 동률은 구체성을 먼저 비교한다. 점수·선택·표시의 이유를 각각 기록한다.
- 기본 본문에는 같은 구간의 호환되는 원고만 조립한다. 지수에 반영한 보완은 사용자용 구간 근거에도 설명한다.
- 기존 회귀·새 조건·두 집단의 전후 비교·실제 읽기·브라우저·인쇄를 검증한다. 작은 검토 ZIP과 큰 증거 ZIP을 나누고 크기·범위를 명시한다.

UI 전면 개편·새 메뉴·외부 API/DB·추적·원격 push·공개 배포는 하지 않는다. 원전·도시 좌표·강약의 독립 검토 대기는 유지한다. 실제 선택 증거가 없는 새 의미를 완성으로 세지 않는다.
